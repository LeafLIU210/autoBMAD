# TD-1 CLI 行为验证报告

## 概述

本报告通过静态代码分析验证新旧 CLI 入口的行为差异。

## 命令等价性分析

- 旧入口命令数: 10
- 新入口命令数: 9
- 命令等价: 否
- 新入口缺失命令: cancel_all_pipelines, cancel_pipeline, clean_pipelines
- 旧入口缺失命令: cancel, clean

## 架构分层分析

- 旧入口架构评分: 7/10
- 新入口架构评分: 10/10
- 分层说明: 新入口采用了命令层->服务层->业务层的分层架构

旧入口架构违规:
- 旧入口直接实例化 HybridOrchestrator
- 旧入口直接实例化 StateManager
- 旧入口在 CLI 层直接调用异步业务逻辑

## 测试对齐分析

- 生产使用旧入口: 是
- 生产使用新入口: 否
- 测试使用旧入口: 否
- 测试使用新入口: 是
- 对齐状态: 错位

## 功能对等性

- 功能对等评分: 13/13

## 结论

**发现严重问题**: 测试入口与生产入口不一致！

- 生产环境通过 `pyproject.toml` 使用旧入口
- 测试代码导入的是新入口
- 这意味着测试通过不等于生产入口安全
