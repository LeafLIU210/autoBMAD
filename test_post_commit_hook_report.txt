### 2. 手动安装步骤
- ✅ 复制 scripts/post-commit 到 .git/hooks/post-commit
- ✅ 设置执行权限 (chmod +x)

### 3. 问题修复

#### 问题1: PowerShell 脚本兼容性
**症状**: #!/usr/bin/env pwsh 报错 (pwsh: command not found)
**原因**: 环境没有安装 pwsh，且 PowerShell v1.0 不支持脚本语法
**解决方案**: 重写为 bash 版本的 post-commit hook

#### 问题2: Python 脚本编码问题
**症状**: UnicodeDecodeError: 'gbk' codec can't decode byte 0x80
**原因**: Windows 上 subprocess 需要明确指定 encoding
**解决方案**: 在所有 subprocess.run() 调用中添加 encoding='utf-8' 参数
