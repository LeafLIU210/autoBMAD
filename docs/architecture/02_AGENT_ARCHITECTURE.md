## 1. Overview

This document details the dual-agent architecture that powers each DocuSwarm node. The system uses a simplified dual-agent pattern: **Independent Agent** (creator) and **Evaluator Agent** (reviewer).

### 1.1 Design Principles

| Principle | Description |
|-----------|-------------|
| **Context Isolation** | Evaluator cannot access Independent's reasoning |
| **Quality First** | Iterative refinement until approval |
| **Embedded Questions** | Questions generated by Independent Agent |
| **Persona Preservation** | Full BMM persona in system prompt with unique communication style |

### 1.2 Agent Inventory

| Agent | Role | SDK API | Kimi Mode | Temperature |
|-------|------|---------|-----------|-------------|
| **Independent** | Creates deliverables and questions | `single_prompt()` | Agent | 0.7 |
| **Evaluator** | Reviews and scores deliverables | `single_prompt()` | Thinking | 0.5 |

## 8. Failure Recovery

### 8.1 Agent Failure Types

| Failure Type | Cause | SDK Exception | Recovery |
|--------------|-------|---------------|----------|
| **API Timeout** | Kimi K2.5 slow response | `APITimeoutError` | SDK 鍐呴儴閲嶈瘯 |
| **Rate Limit** | Exceeded 200 RPM | `ChatProviderError` (429) | SDK 鍐呴儴閫€閬?|
| **Invalid Output** | Malformed JSON | N/A | Retry with guidance |
| **Quality Failure** | Score below threshold | N/A | Iterate or escalate |
| **Max Iterations** | 3 iterations reached | N/A | Force complete or fail |
| **Max Steps** | SDK 姝ラ涓婇檺 | `MaxStepsReached` | 闄嶇骇澶勭悊 |
| **Run Cancelled** | 澶栭儴鍙栨秷璇锋眰 | `RunCancelled` | 娓呯悊骞惰繑鍥?|

### 8.2 Recovery Strategy

```python
from kimi_agent_sdk.exceptions import (
    RunCancelled, MaxStepsReached, ChatProviderError,
    APITimeoutError, APIConnectionError,
)

class AgentRecovery:
    MAX_RETRIES = 3

    async def execute_with_recovery(self, agent, context):
        for attempt in range(1, self.MAX_RETRIES + 1):
            try:
                return await agent.execute(context)
            except ChatProviderError as e:
                if e.status_code == 429:
                    await asyncio.sleep(60)  # Rate limit
                elif attempt < self.MAX_RETRIES:
                    await asyncio.sleep(2 ** attempt)
                else:
                    raise
            except APITimeoutError:
                if attempt < self.MAX_RETRIES:
                    context["timeout"] *= 1.5
                else:
                    raise
            except APIConnectionError:
                if attempt < self.MAX_RETRIES:
                    await asyncio.sleep(2 ** attempt)
                else:
                    raise
            except MaxStepsReached:
                return {"warning": "max_steps_reached", "partial": True}
            except RunCancelled:
                return {"cancelled": True}

        raise MaxRetriesExceededError()
```
