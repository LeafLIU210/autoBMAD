## Dev Notes
- ContextSummarizer 依赖 SessionManager (来自 EPIC-16 SDK Wrapper)，需确保依赖可用
- 摘要生成是异步操作，应在 pipeline 初始化阶段完成，不阻塞节点执行
- 内存优化：长文档内容可能很大，生成摘要后应立即释放原始内容
- 错误处理：若摘要生成失败，应记录错误但不影响 pipeline 继续执行
- 导入路径：`autoBMAD.docuswarm.utils.context_resolver` 和 `autoBMAD.docuswarm.pipeline.context_summarizer`
- 遵循 Ralph's 原则：DRY (避免重复逻辑), KISS (保持实现简单), YAGNI (不超前设计)
