## Dev Notes
- The kimi-agent-sdk depends on kimi-cli (>=1.12.0,<1.13.0) which handles the Wire protocol communication with Kimi K2.5 backend
- The SDK also depends on kosong (>=0.42.0,<0.43.0) which provides message and tool type libraries
- Keep `httpx` dependency retained as it may be needed for non-SDK API calls in Phase 4
- The SDK version pin uses >=0.0.5,<0.1.0 to allow patch updates while preventing breaking changes from minor versions
- Ensure API key environment variable (`KIMI_API_KEY`) is set for SDK to function properly
