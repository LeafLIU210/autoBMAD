## Dev Notes
- The Claude SDK uses a different message structure than Kimi SDK - content is a list of blocks (TextBlock, ToolUseBlock, etc.)
- ToolUseBlock has `id`, `name`, and `input` attributes rather than flat dictionary
- ResultMessage is a separate type that contains tool_calls as a list of dicts with 'name' and 'parameters' keys
- Must maintain consistency with Kimi SDK extraction - same DeliverableMetadata output format
- The extraction should be additive - if Claude format finds deliverables, return them
- Consider supporting both old and new Claude SDK formats if they differ
- Need to handle case sensitivity in tool names if applicable
