## Dev Notes
- The smoke test uses the high-level `prompt()` API from kimi-agent-sdk
- The `yolo=True` parameter enables automatic approval for tool calls during testing
- Tests should be marked with both `@pytest.mark.smoke` and `@pytest.mark.integration`
- The `MessageAggregator` class transforms WireMessages into Message objects
- Test output should clearly display the SDK version for debugging purposes
- Missing API key should produce a clear, actionable error message (not a traceback)
- Tests should use async/await pattern as kimi-agent-sdk is async-native

### Code Structure
```python
import pytest
from kimi_agent_sdk import prompt, Session, MessageAggregator

@pytest.mark.smoke
@pytest.mark.integration
async def test_prompt_basic():
    """Verify basic prompt() API returns messages."""
    messages = []
    async for msg in prompt("Say hello in one word", yolo=True):
        messages.append(msg)
    assert len(messages) > 0

@pytest.mark.smoke
@pytest.mark.integration
async def test_session_lifecycle():
    """Verify Session create/prompt/close lifecycle."""
    session = await Session.create(model="kimi", yolo=True)
    async with session:
        aggregator = MessageAggregator()
        async for wire_msg in session.prompt("What is 1+1?"):
            for msg in aggregator.feed(wire_msg):
                assert msg is not None
        for msg in aggregator.flush():
            assert msg is not None
```
