## Dev Notes
- Each tool must follow the same implementation pattern as Story 18.3 (create_deliverable)
- All tools must use `ToolResult` dataclass for return type (not ToolOk/ToolError)
- Parameter validation must use Pydantic BaseModel classes
- File paths and I/O operations should remain unchanged - only the interface changes
- Error handling must catch exceptions and return `ToolResult(success=False, output="", error=str(exc))`
- The ToolRegistry registration should happen at module import time or via explicit `register_all_tools()` call
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor for all implementations
