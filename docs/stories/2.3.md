## Dev Notes
- Tools must follow OpenAI Functions format (not Tools format) for compatibility with Kimi K2.5 Agent mode
- The `create_deliverable` tool enables the Independent Agent to output structured markdown documents
- The `update_context` tool allows the agent to share information with other nodes via the shared subject context
- The `operation` parameter in `update_context` supports three modes:
  - `set`: Overwrites the entire value at the specified key
  - `append`: Adds to an existing list or creates a new list if key doesn't exist
  - `remove`: Deletes a key or removes specific items from a list
- Tool execution should be synchronous (not async) as the LLM handles async internally
- Consider adding type hints throughout for better IDE support and type checking
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
