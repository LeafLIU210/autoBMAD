## Dev Notes
- The SessionManager acts as the central interface between the SDK wrapper and agents
- Current implementation likely uses Kimi SDK Message objects that need conversion to dict
- The dict format should follow Claude SDK standard: `{"role": "user"|"assistant"|"system", "content": str|list}`
- When content is a list, it may contain text blocks and tool_use blocks for tool invocations
- Consider handling the case where content might be None or malformed
- Ensure backward compatibility with existing agent code that expects dict format

### Key Implementation Details
```python
# Convert SDK result messages to dict format
def _convert_to_dict_format(self, sdk_messages) -> list[dict[str, Any]]:
    """Convert SDK messages to dict format"""
    messages: list[dict[str, Any]] = []
    for msg in sdk_messages:
        messages.append({
            "role": msg.role,
            "content": msg.content,
        })
    return messages
```
