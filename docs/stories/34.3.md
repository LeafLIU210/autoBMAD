## Dev Notes
- **Path Correction**: The authoritative configuration file is at `autoBMAD/nodes/ux/node.yaml`. The old `nodes/ux/node.yaml` path is deprecated and should not be modified.
- **Configuration Format**: Use the unified full access configuration pattern:
  ```yaml
  tools:
    allowed_builtin_tools: ["Read", "Glob"]
    file_permissions:
      allowed_read_dirs:
        - "docs/"
    search_permissions:
      search_dirs:
        - "docs/"
  ```
- **Security**: PathValidator handles security at multiple layers:
  - Directory whitelist with prefix matching
  - Symlink resolution (realpath)
  - File type restrictions (extension whitelist/blacklist)
  - Directory pattern blocking (.git, .env, node_modules, etc.)
- **Simplification**: Use `docs/` as the root directory - PathValidator automatically handles subdirectory access, eliminating the need to list subdirectories like `docs/research/` explicitly.
- **Consistency**: Ensure the configuration matches the format used in analyst, pm, architect, and po nodes for maintainability.
