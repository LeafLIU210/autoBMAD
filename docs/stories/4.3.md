## Story
**As a** developer,
**I want to** separate shared and private memory between agents,
**So that** context isolation is maintained at the memory level.

## Acceptance Criteria
- [x] Shared memory accessible by both Independent and Evaluator agents
- [x] Private memory isolated per agent type (Independent-only or Evaluator-only)
- [x] Memory keys are clearly typed using MemoryScope enum
- [x] No cross-contamination between agent memories
- [x] Memory persists appropriately across node iterations
- [x] Clear methods for reading, writing, and clearing memory by scope

## Dev Notes
- Use Python `enum.Enum` for MemoryScope type safety
- Integrate with structlog using `structlog.get_logger().bind(component="MemoryManager")`
- Consider thread-safety for async operations (use asyncio.Lock if needed)
- Independent Agent memory should NOT be accessible to Evaluator
- Evaluator Agent memory should NOT be accessible to Independent
- Shared memory is readable by both but writable by neither (read-only context)
- Memory should be cleared appropriately between node runs to prevent state leakage
- All methods should include type hints for clarity
