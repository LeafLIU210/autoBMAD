## Dev Notes

- **Test File Location**: `tests/nodes/test_dual_agent_multi_iteration.py`
- **Mock Strategy**: Use unittest.mock to create mock agents with configurable return values per call
- **Iteration Feedback Structure**: The feedback should include:
  ```python
  iteration_feedback = {
      "score": 0.7,
      "issues": ["Issue 1", "Issue 2"],
      "suggestions": ["Fix suggestion 1", "Fix suggestion 2"],
      "verdict": "NEEDS_REVISION"
  }
  ```
- **Verdict Types**: NEEDS_REVISION, APPROVED, FORCE_APPROVED, BLOCKED
- **Escalation Threshold**: 0.5 - scores above this trigger force completion after max iterations
- **Test Isolation**: Each test should reset mocks and create fresh DualAgentNode instance
- **Assertion Strategy**: Use both direct value assertions and mock call count verification
