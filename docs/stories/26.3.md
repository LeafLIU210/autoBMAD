## Dev Notes
- **Role Correction**: The current `role` field incorrectly says "Project Manager" but this node performs Product Manager functions (creating PRDs, defining requirements). This must be corrected to maintain semantic accuracy.
- **Task Name Convention**: Follow the pattern `create-{artifact-type}` used across all nodes: analyst uses `create-business-analysis-report`, pm uses `create-product-requirements-document`, etc.
- **Communication Style**: Should emphasize clarity, structure, and stakeholder alignment - typical PM traits like "structured documentation", "scope boundary enforcement", "acceptance criteria precision"
- **Critical Actions**: Should include PM-specific responsibilities like "Clarify ambiguous requirements", "Identify scope creep risks", "Define measurable acceptance criteria", "Align stakeholders on priorities", "Document scope boundaries explicitly"
- **Memories**: Should help the agent maintain context about its role, such as "I am the second node in the pipeline, receiving analysis from the analyst", "My output feeds directly to the UX designer", "I must create implementable, testable requirements"
- **Evaluator Changes**: The `thresholds` → `threshold` change aligns with Epic 26's goal of field name consistency across all 5 nodes
- **No v1 Compatibility**: This is a breaking change - do NOT implement fallback logic for v1 format
- **Default Values**: If `runtime` values are not specified elsewhere, use sensible defaults: timeout=300, retry_max_attempts=3, retry_backoff=1.5
