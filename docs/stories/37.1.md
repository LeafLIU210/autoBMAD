- **File Location**: `autoBMAD/docuswarm/pipeline/state.py`
- **Field Placement**: Add the new field at the end of the TypedDict, after `shared_context: dict[str, Any]`
- **Field Comment**: Use the following comment format:

- **Type Considerations**: The field type `list[dict[str, Any]]` matches the structure of resolved document summaries containing metadata and content references
- **LangGraph Compatibility**: `PipelineState` is used with LangGraph's `StateGraph`, which requires TypedDict. The new field must conform to TypedDict constraints (no default values in the class definition)
- **Serialization**: LangGraph handles `PipelineState` serialization automatically via checkpointing. Since `list[dict[str, Any]]` is JSON-serializable, no custom serialization logic is needed
- **Backward Compatibility**: The `create_initial_state()` function will be updated in Story 37.2 to accept this field; for now, the field just needs to exist in the type definition
