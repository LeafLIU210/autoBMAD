## Dev Notes
- The IndependentAgent currently uses KimiClient for LLM interactions; this story migrates to the SDK Session API
- Wire messages are streaming messages from the SDK that need aggregation into complete LLM responses
- `MessageAggregator` from the SDK handles buffering and combining partial messages
- `ApprovalRequest` is an SDK-specific type that must be resolved before continuing
- The `yolo=True` flag enables auto-approval for tool executions (appropriate for independent agents)
- Need to preserve existing logging with `structlog` throughout the migration
- Consider dual-support during transition: keep KimiClient path as fallback until fully validated
- The `_process_message()` method needs to be updated to handle SDK `Message` types instead of `ChatResponse`
