## Dev Notes
- **SessionManager Dependency**: ContextSummarizer requires SessionManager from the Claude SDK wrapper (EPIC-16). Use dependency injection in constructor.
- **Token Estimation**: 50K characters ≈ 12.5K tokens (using 4 chars/token ratio)
- **Prompt Engineering**: The SUMMARIZE_PROMPT should explicitly instruct the LLM to output ONLY the summary, no additional commentary
- **Error Handling**: When document.exists is False or document.content is empty, return formatted error message instead of calling LLM
- **Batch Processing**: summarize_all should process documents sequentially to avoid rate limiting, not in parallel
- **Content Truncation**: Truncate at max_content_length, then append "\n\n[... content truncated ...]" to indicate incomplete content
- **Title Extraction**: First line of content is checked for H1 heading (# title). If found, use it as title; otherwise use resolved_path.stem
