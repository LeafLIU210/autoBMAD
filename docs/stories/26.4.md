## Dev Notes
- **Schema v2 结构参考**:
  ```yaml
  schema_version: "2.0"
  task:
    name: create-ux-design-specification
    description: "Create comprehensive UX design specification including user flows, wireframes, and interaction patterns"
    role_supplement: "Focus on user-centered design principles and accessibility"
  runtime:
    timeout: 300
    retry_max_attempts: 2
    retry_backoff: 1.5
  evaluator:
    inline: evaluator.yaml
  ```
- **Persona 新增字段结构**:
  ```json
  {
    "communication_style": ["visual", "structured", "user-focused"],
    "critical_actions": [
      "Conduct user research and create user personas",
      "Design intuitive navigation and information architecture",
      "Create detailed wireframes with textual descriptions for AI interpretation",
      "Define interaction patterns and micro-interactions",
      "Validate designs against accessibility standards (WCAG 2.1 AA)"
    ],
    "memories": [
      "Mobile-first design is non-negotiable",
      "Always provide text alternatives for visual wireframes",
      "Consistency in design systems reduces cognitive load"
    ]
  }
  ```
- **线框图文本描述说明**: 由于 AI 无法直接"看见"图像，`critical_actions` 第 3 条必须明确要求使用文本描述线框图布局、组件位置和交互行为
- **不实现 v1 兼容**: 直接升级到 v2，如果缺少 `task` 段落，NodeLoader 应抛出配置错误
- **字段名修正**: `evaluator.yaml` 中的 `thresholds` → `threshold` 必须与 NodeEvaluatorConfig 数据类一致
