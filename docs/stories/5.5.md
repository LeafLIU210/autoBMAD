## Dev Notes
- Force completion should only occur when both conditions are met:
  1. Current iteration >= max_iterations (default: 3)
  2. Alignment score >= escalation threshold (default: 0.50) but < approval threshold (default: 0.70)
- The warning message should be human-readable and include the node ID, final score, thresholds, and unresolved issues
- Force completion metadata should be stored in node_run_results table for audit purposes
- Consider adding a `force_completed` boolean flag to NodeRunMetrics for tracking
- Force completion is distinct from BLOCKED verdict - BLOCKED occurs when score < escalation threshold
- The warning should be logged at WARNING level and surfaced to user via CLI output
