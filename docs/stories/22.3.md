## Story
**As a** AI Agent (IndependentAgent),
**I want** to implement a `_format_task_section()` method that formats the task assignment section of the system prompt,
**So that** agents can understand their specific task assignments with clear role context.

## Acceptance Criteria

### AC1: Basic Task Formatting
- [x] **Given** a `NodeTaskConfig` instance with `name` and `description` populated
- [x] **When** I call `_format_task_section(task)`
- [x] **Then** it returns a formatted string containing "## Task Assignment" header
- [x] **And** the task name is displayed as "You are executing the '{task.name}' task."
- [x] **And** the task description is included in the output

### AC2: Null Task Handling
- [x] **Given** `None` is passed as the task parameter
- [x] **When** `_format_task_section(None)` is called

### AC3: Role Context Supplement
- [x] **Given** a `NodeTaskConfig` instance with `role_supplement` field populated
- [x] **When** the section is formatted
- [x] **Then** "### Role Context" subsection is included
- [x] **And** the role_supplement text is displayed after the subsection header

### AC4: No Role Context
- [x] **Given** a `NodeTaskConfig` instance with empty or null `role_supplement`
- [x] **When** the section is formatted
- [x] **Then** the Role Context subsection is omitted entirely
- [x] **And** the output contains only the header, task name, and description

### AC5: Method Signature

- [x] **When** the code is analyzed
- [x] **Then** it accepts `task: NodeTaskConfig | None` as parameter
- [x] **And** returns `str` type
