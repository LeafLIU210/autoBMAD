- **Mock Path Changes**: If `_validate_context` was moved during refactoring, mocks referencing `autoBMAD.docuswarm.orchestrator._validate_context` will fail. Update to new qualified path.
- **Coverage Baseline**: Pre-refactoring baseline should be retrieved from CI/CD history or previous test runs. Do not let coverage drop below this threshold.
- **Import Errors**: If tests fail with `ImportError`, check that all moved classes are properly exported from their new modules and imports are updated in both source and test files.
- **Schema v2 Impact**: The loader now uses Schema v2 which changes how `task.name` is accessed. Tests validating node configuration must be updated to use the new field path.
