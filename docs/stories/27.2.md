## Dev Notes

### Private Field Detection Logic
- Private fields are identified by the `_` prefix convention
- Check must be **recursive** through nested structures (dicts, lists)
- Must handle circular references gracefully (use `visited` set with id())
- Edge case: `__init__`, `__dict__` are NOT private fields (Python dunder methods)

### Strategy Implementation Pattern
```python
class PrivateFieldIsolationStrategy(ValidationStrategy):
    def validate(self, data: dict, context: dict | None = None) -> ValidationResult:
        issues = []
        self._check_recursive(data, [], issues, set())
        return ValidationResult(
            valid=len(issues) == 0,
            issues=issues,
            warnings=[]
        )
```

### Error Handling Contract
- `ContextIsolationError` message format must remain unchanged for backward compatibility
- Error should include path to leaked field: `"Private field '_internal_state' found at path ['data', 'nodes', 0]"`
- Do NOT change exception type - caller expects `ContextIsolationError`

### Migration Strategy
- This is a **direct replacement**, not a deprecation
- No backward compatibility aliases needed
- All code paths must be updated in single PR
- Coordinate with Story 27.1 (framework creation) - this story depends on it
