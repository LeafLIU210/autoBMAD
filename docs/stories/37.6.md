# Story 37.6: Support Pipeline Resume with Cached Summaries

## Status

**Status**: Ready for Done

**Last Updated**: 2026-04-07 09:31:40

## Story
**As a** pipeline user,
**I want** the `docs_context_summary` cache to be properly restored when resuming a paused pipeline,
**so that** the pipeline can continue execution without rebuilding the document context from scratch, maintaining performance and consistency.

- [x] Warning logged when summary missing from checkpoint
- [x] No error thrown when summary missing (graceful fallback)

### Technical Implementation Details

**Target Method**: `resume_pipeline()` in `autoBMAD/docuswarm/pipeline/orchestrator.py`

**Current State Restoration Logic** (lines 477-486):
```python
# Restore state from checkpoint
initial_state["current_node"] = checkpoint_state.get("current_node")
initial_state["completed_nodes"] = checkpoint_state.get("completed_nodes", [])
initial_state["deliverables"] = checkpoint_state.get("deliverables", {})
initial_state["questions"] = checkpoint_state.get("questions", {})
initial_state["evaluations"] = checkpoint_state.get("evaluations", {})
initial_state["node_iterations"] = checkpoint_state.get("node_iterations", {})
initial_state["session_ids"] = checkpoint_state.get("session_ids", {})
initial_state["session_metadata"] = checkpoint_state.get("session_metadata", {})
initial_state["current_node_session_id"] = session_id if session_resumed else None
initial_state["status"] = RUNNING
```

**Required Changes**:
1. Extract `docs_context_summary` from `checkpoint_state` after line 426 where other checkpoint data is extracted:
   ```python
   docs_context_summary = checkpoint_state.get("docs_context_summary", [])
   ```

2. Add warning log when `docs_context_summary` is missing (empty list indicates missing):
   ```python
   if not docs_context_summary:
       logger.warning(
           "docs_context_summary_missing_from_checkpoint",
           pipeline_id=pipeline_id,
           fallback_behavior="context_builder will rebuild from disk",
       )
   ```

3. Restore `docs_context_summary` in the state restoration block (around line 486):
   ```python
   initial_state["docs_context_summary"] = docs_context_summary
   ```

### Backward Compatibility
The implementation must handle backward compatibility with old checkpoints that don't have `docs_context_summary`:
- Use `.get("docs_context_summary", [])` to default to empty list
- Empty list triggers the fallback behavior in `context_builder.build()` (implemented in Story 37.4)
- No exceptions should be raised for missing field

### Logging Standards
Use `structlog` logger (already imported as `logger`) with structured logging:
- Event name: snake_case describing the action
- Include `pipeline_id` for traceability
- Use `logger.warning()` for fallback scenarios
- Use `logger.info()` for successful restoration
