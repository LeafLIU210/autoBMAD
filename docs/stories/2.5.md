## Dev Notes
- **Persona Schema**: Each persona.json must contain: name, role, identity, expertise (array), principles (array), communication_style, output_format
- **File Location**: Persona files reside in `nodes/{node_id}/persona.json` relative to project root
- **Token Limits**: Keep system prompts under 8000 characters to ensure adequate context for LLM
- **Error Handling**: Raise descriptive FileNotFoundError if persona file missing; raise ValueError if schema invalid
- **BMAD Principles**: Follow Ralph's principles - DRY, KISS, YAGNI, Occam's Razor
- **Type Hints**: Use TypedDict for persona structure; include Optional for nullable fields
- **Logging**: Use structlog to log persona loading attempts and any validation warnings
