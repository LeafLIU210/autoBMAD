## Dev Notes
- The universal criteria include: completeness (0.30), clarity (0.20), consistency (0.20), actionability (0.20), evidence_quality (0.10) - these serve as defaults
- Node-specific overrides should be additive to universal weights, not replacements
- Example: Analyst node has evidence_quality: 0.40 which overrides the default 0.10
- Use PyYAML for loading configuration files
- Consider adding a `merge_weights()` function that combines universal + node-specific weights
- Thresholds: approval (0.70), escalation (0.50) should be configurable per node
- Follow Ralph's principles: DRY (use shared schema), KISS (simple YAML structure), YAGNI (only needed criteria fields)
