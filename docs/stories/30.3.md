## Dev Notes
- **Baseline Source**: Use metrics from `docs/research/refactor-2026-03-26/baseline-metrics.md` as the performance baseline. If file doesn't exist, run benchmarks against the commit prior to EPIC-25.
- **Benchmark Framework**: Use `pytest-benchmark` for consistent measurement and statistical analysis across multiple runs.
- **Isolation Strategy Comparison**: The original `PrivateFieldIsolationStrategy` implementation is in `autoBMAD/docuswarm/context/isolation.py`. Ensure benchmarks test the same object hierarchies for fair comparison.
- **Token Measurement**: Token consumption is measured via `token_usage` field in Claude SDK response. Mock responses should include realistic token counts based on production logs.
- **Node Execution Timing**: Use `time.perf_counter()` for high-resolution timing. Start timing before `NodeExecutor.execute()` and end after context persistence completes.
- **Warm-up Runs**: Perform 2 warm-up runs before actual benchmarking to account for Python module caching and JIT optimizations.
- **Environment Requirements**: Benchmarks must be run on dedicated hardware without other processes. Document CPU, RAM, and disk specs for reproducibility.
- **Threshold Tolerance**: +10% threshold is calculated as: `(new_time - baseline_time) / baseline_time <= 0.10`
- **Registry Performance**: `ValidationRuleRegistry.get()` should use dictionary lookup internally, achieving O(1) complexity naturally.
