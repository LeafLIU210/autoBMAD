## Implementation Details
```python
from dataclasses import dataclass, field
from pathlib import Path


@dataclass
class ReferencedDocument:
    """Represents a document referenced via @ path syntax in context content.

    Attributes:
        original_reference: The original @ reference string (e.g., "@docs/guide.md")
        resolved_path: The resolved absolute Path to the referenced file
        content: The raw content of the referenced file
        summary: AI-generated summary of the document content (filled by ContextSummarizer)
        exists: Whether the referenced file exists at the resolved path
        error: Error message if resolution failed or file doesn't exist
    """
    original_reference: str
    resolved_path: Path
    content: str
    summary: str = ""
    exists: bool = True
    error: str | None = None


@dataclass
class ResolvedContext:
    """Holds the complete result of resolving @ references in context content.

    Attributes:
        original_content: The original context content with @ references intact
        cleaned_content: Context content with all @ references removed
        referenced_documents: List of ReferencedDocument objects found in content
        total_tokens_estimate: Estimated token count for all referenced documents
    """
    original_content: str
    cleaned_content: str
    referenced_documents: list[ReferencedDocument] = field(default_factory=list)
    total_tokens_estimate: int = 0
```
