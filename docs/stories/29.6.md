## Story

**As a** agent system architect,
**I want** the prompt architecture restructured into 4 distinct layers,
**So that** Claude correctly distinguishes identity instructions from task content, enabling more accurate agent behavior and cleaner separation of concerns.

## Dev Notes

### 四层架构设计

```
┌─────────────────────────────────────────────────┐
│ Layer 1: claude_code preset（工具说明、安全指令） │  ← SDK 内置
│ Type: preset, Name: "claude_code"               │
├─────────────────────────────────────────────────┤
│ Layer 2: Persona（角色身份、专业领域、行为准则）  │  ← personas/{id}.json
│ 例如: "你是经验丰富的产品分析师，专注于..."        │
├─────────────────────────────────────────────────┤
│ Layer 3: Task Context（任务名、交付物要求）       │  ← node.yaml task{}
│ 例如: "当前任务: 创建用户故事，交付物: markdown"   │
├─────────────────────────────────────────────────┤
│ Layer 4: Skill Injection（BMAD 命令描述）         │  ← .claude/skills/
│ 例如: "可用命令: bmad-agent-analyst..."          │
└─────────────────────────────────────────────────┘
                              ↓
                    ClaudeAgentOptions
                              ↓
┌─────────────────────────────────────────────────┐
│ User Prompt: 纯任务内容                           │
│ - 上下文文档引用                                  │
│ - 具体任务指令                                    │
│ - 用户输入                                        │
│ - 迭代反馈                                        │
└─────────────────────────────────────────────────┘
```

### ClaudeAgentOptions 格式

```python
from claude_agent_sdk import ClaudeAgentOptions

options = ClaudeAgentOptions(
    system_prompt={
        "type": "preset",
        "preset": "claude_code",  # Layer 1
        "append": "\n\n" + "\n".join([
            persona_section,      # Layer 2
            task_section,         # Layer 3
            skills_section        # Layer 4
        ])
    },
    allowed_tools=[
        "mcp__docuswarm-files-{node_id}__read_document",
        "mcp__docuswarm-search-{node_id}__grep_search",
        # ... other tools
    ]
)
```

### Token 预算分配建议

| 层级 | 预算 (tokens) | 说明 |
|------|---------------|------|
| Layer 1 (preset) | ~1500 | SDK 内置，不可控 |
| Layer 2 (Persona) | ~400 | 角色描述 |
| Layer 3 (Task) | ~300 | 任务上下文 |
| Layer 4 (Skills) | ~800 | BMAD 技能描述 |
| **Total** | **≤3000** | 留出 200 buffer |

### 风险点

1. **Breaking Change**: 删除 `_call_llm_via_session` 后无 fallback，需确保新架构稳定
2. **Token 超限**: Skills 层内容可能过长，需实现截断逻辑
3. **Persona 解析**: 确保从 JSON 正确解析 persona 内容
