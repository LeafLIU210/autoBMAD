### Risk Mitigations to Test
| Risk | Test Coverage |
|------|---------------|
| SDK `setting_sources` fails to load | Test with invalid/empty `setting_sources` values |
| Skills index too large → context overflow | Test whitelist limit enforcement (≤10 skills) |
| Claude selects wrong skill | Not directly testable - but verify descriptions are clear |
| Existing system prompt conflict | Test backward compatibility with old node configs |

### Testing Standards
- **Framework**: pytest with pytest-mock for mocking
- **Test Location**: `tests/test_skills_integration.py` (new file)
- **Naming**: Test functions prefixed with `test_`, descriptive names
- **Coverage**: Minimum 80% line coverage for new code
- **Fixtures**: Use pytest fixtures for reusable mock setups
- **Isolation**: Each test should be independent, use `tmp_path` for file operations
