## Story

**So that** the @ references are removed from content and the resulting text is clean, properly formatted, and includes accurate token estimates.

## Acceptance Criteria
- [x] `@path` references are completely removed from the cleaned content

- [x] Leading and trailing whitespace is removed from the content
- [x] Token count is estimated based on referenced document content (using CHARS_PER_TOKEN ratio)
- [x] The `ResolvedContext` object contains both original and cleaned content for debugging
- [x] Empty lines left after @ reference removal are handled properly (not creating excessive blank lines)

## Dev Notes
- The CHARS_PER_TOKEN constant should be defined as 4 (standard approximation: 1 token ≈ 4 characters)
- The PATH_PATTERN regex is already defined in ContextResolver class for finding @ references
- Token estimation should only count content from documents that exist (doc.exists == True)
- The cleaned content should preserve the structure of the original content except for @ references and extra whitespace
- Consider using regex for efficient @ reference removal: `re.sub(r'@[\w./\-\u4e00-\u9fff]+\.(?:md|txt|yaml|json)', '', content)`
- The _cleanup_content method should use re.compile for better performance when called multiple times
