## Dev Notes
- [Note 1]: The `ValidationResult` dataclass follows the pattern used elsewhere in the project for result objects
- [Note 2]: Default values are required for optional fields (`raw_response`, `attempts`, `fallback_used`) since dataclasses require non-default fields before default fields
- [Note 3]: Use `str | None` syntax instead of `Optional[str]` for Python 3.11+ compatibility
- [Note 4]: The `attempts` field defaults to 1 (first attempt), representing the number of attempts made
- [Note 5]: The `fallback_used` field indicates whether the validator fell back to a permissive state after all retries failed
- [Note 6]: Consider adding `__post_init__` validation if needed in the future, but keep it simple for now (YAGNI)
