## Dev Notes
- **Flat Layout**: The project uses a flat layout (not `src/` layout) per `project-structure.md`. The `docuswarm/` package sits directly in the repository root.
- **Lazy Imports in `__init__.py`**: Since most subpackages won't have implementations yet, `__init__.py` should use lazy imports or conditional imports to avoid `ImportError` on modules that are only stubs. Consider initially exporting only `__version__` and adding class exports as stories are completed.
- **Python 3.14 Requirement**: The project requires Python 3.14+. Ensure the development environment has this version. This enables modern type hint syntax (`X | Y` union types, `TypedDict`, etc.).
- **Coding Standards**: Follow `coding-standards.md` conventions — Google-style docstrings, 100-char line length, import ordering (stdlib > third-party > local), `snake_case` for modules/functions, `PascalCase` for classes.
- **Minimal Stubs**: For files like `config.py` and `exceptions.py`, create minimal stubs with class signatures only. Full implementations are covered by Stories 1.2 and 1.3 respectively.
- **CLI Placeholder**: `main.py` only needs a basic Click group with `--help` working. Full CLI commands are implemented in Story 1.7.
- **No External Dependencies at Runtime Yet**: The `__init__.py` should not fail if optional dependencies like `langgraph` aren't configured — the import should be safe without any API keys or database.
- **File Encoding**: All files must be UTF-8 encoded per coding standards.
