## Story
**As a** developer,
**I want to** integrate context isolation components (ContextManager, ContextFilter, IsolationAuditLogger) into the DualAgentNode,
**So that** all node executions maintain proper isolation between the Independent Agent and Evaluator Agent, preventing private reasoning from leaking into the evaluation process.

## Dev Notes
- The DualAgentNode should receive ContextManager, ContextFilter, and IsolationAuditLogger as constructor dependencies (dependency injection pattern)
- ContextManager must be used to build BOTH independent and evaluator contexts - never build contexts manually
- ContextFilter.filter_for_evaluator() MUST be called after Independent Agent execution and BEFORE Evaluator execution
- All audit events should include run_id and node_id for traceability
- The audit logger should log context_keys on build to verify no private fields included for Evaluator
- Filter operation should log fields_removed to prove private data was stripped
- Follow the execution flow: Independent Context → Independent Execute → Filter → Evaluator Context → Evaluator Execute → Return NodeResult
- Use NodeRunState type from existing node definitions
- Ensure async/await is properly handled for all agent executions
