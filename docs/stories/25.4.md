## Dev Notes
- Use `pytest.raises(ImportError)` to verify that removed symbols cannot be imported
- Use `pathlib.Path.exists()` to verify file system state
- Keep tests lightweight and fast - they are architecture guards, not integration tests
- Consider using `__import__` or `importlib.import_module` for dynamic import testing
- Tests should be self-contained and not depend on other test state
- If tests fail due to legitimate re-introduction of code, the Epic owner should be consulted
- Architecture tests serve as documentation of intentional design decisions
