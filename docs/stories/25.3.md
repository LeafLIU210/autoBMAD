## Story

**As a** developer,
**I want** `evaluator_criteria` to be loaded directly from `evaluator.yaml` at the consumption point,
**So that** it's no longer unnecessarily relayed through `NodeExecutionContext`, simplifying the protocol and eliminating dead data flow.

## Dev Notes

### 当前数据流（修改前）
```
context_builder.py
  ↓ 构建
NodeExecutionContext(evaluator_criteria=...)
  ↓ 传递
isolation.py::build_evaluator_input(context)
  ↓ 读取
context.evaluator_criteria
```

### 目标数据流（修改后）
```
isolation.py::build_evaluator_input(node_id)
  ↓ 直接加载
NodeLoader().load(node_id).evaluator
  ↓ 返回
EvaluatorAgentInput(criteria=...)
```

### 技术考虑

1. **性能影响**: `NodeLoader` 已实现内部缓存机制（`_cache` 字典），重复加载同一 node 时返回缓存实例，无文件 I/O 开销，性能影响可忽略。

2. **NodeLoader 使用**:
   ```python
   from autoBMAD.docuswarm.node_management.loader import NodeLoader

   node = NodeLoader().load(node_id)
   criteria = node.evaluator  # 直接使用，无需中转
   ```

3. **错误处理**: `NodeLoader.load()` 在 node 不存在时会抛出 `NodeNotFoundError`，调用方需确保传入有效的 `node_id`。

4. **契约变更**: 此修改是**破坏性变更**，不保留向后兼容。由于这是 Phase 1 清理任务，且 `evaluator_criteria` 之前是可选字段，实际影响范围可控。

5. **相关文件检查**: 建议执行以下命令确认影响范围：
   ```bash
   grep -r "evaluator_criteria" autoBMAD/ --include="*.py"
   grep -r "evaluator_criteria" tests/ --include="*.py"
   ```
