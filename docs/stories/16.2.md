## Dev Notes
- The `base_url` parameter should prefer explicitly provided value over environment variable
- If `base_url` is `None` and `ANTHROPIC_BASE_URL` is not set, use `DEFAULT_BASE_URL`
- The `api_key` defaults to empty string if neither parameter nor environment variable is set
- Use the project's existing structlog logger instance (import from `autoBMAD.docuswarm.utils.logger`)
- Follow Ralph's principles: Keep the initialization simple (KISS), don't add features not needed (YAGNI)
- Ensure the class is exported in `llm/__init__.py`

### Implementation Detail
```python
class ClaudeSDKWrapper:
    DEFAULT_BASE_URL = "https://api.kimi.com/coding/"

    def __init__(
        self,
        base_url: str | None = None,
        api_key: str | None = None,
        permission_mode: str = "bypassPermissions",
    ) -> None:
        self.base_url = base_url or os.getenv(
            "ANTHROPIC_BASE_URL",
            self.DEFAULT_BASE_URL
        )
        self.api_key = api_key or os.getenv("ANTHROPIC_API_KEY", "")
        self.permission_mode = permission_mode
        self._logger = logger.bind(component="ClaudeSDKWrapper")
```
