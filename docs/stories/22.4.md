## Dev Notes
- This method is a `@staticmethod` that takes a `NodeDeliverableConfig` instance as parameter
- The method should return a formatted markdown string for the deliverable requirements section
- Must handle both cases: with and without `template_title` (optional field)
- Follow the same formatting pattern as `_format_persona_section()` and `_format_task_section()`
- The `required_sections` should be formatted as a markdown bullet list using "- {section}" format
- Placeholder in `template_title` (e.g., `{PROJECT_NAME}`) must be preserved for runtime substitution
- The method signature should match: `def _format_deliverable_section(deliverable: NodeDeliverableConfig) -> str:`
