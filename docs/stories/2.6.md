## Dev Notes
- The Independent Agent uses Kimi K2.5 Agent mode (not Thinking or Instant) to enable complex reasoning and tool calling
- System prompt must include full persona from `nodes/{node_id}/persona.json` including role, identity, expertise, principles, and communication_style
- Output must be validated against IndependentOutput TypedDict to ensure schema compliance
- Private reasoning is critical for debugging but MUST be filtered before passing to Evaluator Agent
- Tool definitions come from `llm/tools.py` (DOCUSWARM_TOOLS constant)
- Questions should be generated in three categories: blocking (critical, stops node), clarifying (important for quality), optional (nice to have)
- The agent should use the persona's communication_style and output_format preferences
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor in implementation
- Use async/await for all LLM calls to support concurrency
- Import typing for Dict, Any, List, Optional, Literal from standard library
