## Dev Notes
- The commands require access to the QuestionHandler and StateManager from the CLI entry point
- Question IDs are formatted as `{node_id}_{run_id[:8]}_{index}` - this format should be documented or validated
- The CLI uses Rich Console for colored output - use appropriate styling:
  - `[red bold]` for blocking questions
  - `[yellow]` for clarifying questions
  - `[dim]` for optional questions
  - `[green]` for success messages
- Consider adding tab-completion for node names if feasible
- The `answer` command should accept multi-word answers (use `@click.argument(..., nargs=-1)` or quote the answer)
- Need to handle async properly - the QuestionHandler.answer_question() is async
- Consider adding a `docuswarm questions --all` flag to show all runs or answered questions
