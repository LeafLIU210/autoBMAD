## Dev Notes
- The KimiSessionManager serves as the primary SDK adapter layer for all agent interactions
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
- Use `KaosPath` for path handling (from kaos module)
- Config can be passed as Config object or Path to config file
- Session IDs should be generated using UUID if not provided
- The `_active_sessions` dict should use session_id as key and Session object as value
- Ensure proper cleanup on `close_all()` to avoid resource leaks
- Consider using `try/finally` for cleanup in async context manager
- The `yolo` parameter controls auto-approval for tool calls (True = auto-approve for IndependentAgent)
- Mode parameter maps to SDK modes: "instant", "thinking", "agent"
