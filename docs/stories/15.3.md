## Dev Notes
- **Path Resolution Logic**: 当 context_file_path 被提供时，`@./local/file.md` 应该解析为 `context_file_path.parent / "local/file.md"`
- **Fallback Behavior**: 如果 context_file_path 为 None，应该使用当前工作目录作为基准，即 `Path.cwd() / "local/file.md"`
- **Security**: 即使是相对路径解析，仍然需要通过 `_is_safe_path` 检查，防止通过 `../../../etc/passwd` 进行路径遍历攻击
- **Edge Cases**:
  - `@./` 单独出现时应忽略（无有效路径）
  - `@./file.md` 和 `@file.md` 应该被区别对待（后者为 @docs/ 解析）
  - 需要处理 `./` 和 `../` 混合的路径，如 `@./../dangerous.md`（应被阻止）
