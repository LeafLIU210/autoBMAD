## Dev Notes
- The handler follows the kimi-agent-sdk's approval handler pattern using a callback function
- Action lists use Python sets for O(1) lookup performance
- Conservative policy for unknown actions (approve single) prevents blocking legitimate operations
- The `auto_approve_all` flag bypasses all checks for development/testing scenarios
- Must import `ApprovalRequest` type from the SDK for type hints
- Handler should be instantiated per-session to support different configurations
- Logging should capture approval decisions for audit purposes
