## Story
**As a** developer configuring BMAD nodes,
**I want** to add a `skill_ref` field to the NodeTaskConfig dataclass,
**So that** each node can reference its corresponding BMAD skill for proper skill invocation during agent initialization.

## Dev Notes
- The `NodeTaskConfig` dataclass is located in `autoBMAD/nodes/loader.py`
- The `_build_node_config()` method handles parsing of node.yaml files into configuration objects
- Use Python 3.10+ union type syntax (`str | None`) for type hints
- Field should be optional to maintain backward compatibility with existing node configurations
- This field will be used by `IndependentAgent` to inject skill invocation hints into system prompts (Story 32.7)
- Example YAML structure to parse:
  ```yaml
  task:
    name: create-product-brief
    description: Create compelling product briefs...
    skill_ref: bmad-product-brief
  ```
