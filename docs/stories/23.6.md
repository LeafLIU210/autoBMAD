## Dev Notes

### Test Implementation Approach
- Use `inspect` module to verify functions/classes are not defined in modules
- Use `ast` module for deeper code structure analysis if needed
- Use `pathlib.Path.rglob()` for recursive file scanning
- Tests should fail fast with clear error messages indicating what still exists

### File Path Assumptions
- Codebase root: `autoBMAD/docuswarm/`
- Test directory: `tests/`
- Scripts directory: `scripts/`

### Key Test Patterns
```python
# Verify function is removed
def test_function_removed():
    import importlib
    module = importlib.import_module('docuswarm.pipeline.graph')
    assert not hasattr(module, '_create_default_node_executor'), \
        "_create_default_node_executor should be removed"

# Verify required parameter
def test_session_manager_required():
    import inspect
    from docuswarm.pipeline.graph import create_pipeline_graph
    sig = inspect.signature(create_pipeline_graph)
    param = sig.parameters.get('session_manager')
    assert param is not None, "session_manager parameter must exist"
    assert param.default == inspect.Parameter.empty, \
        "session_manager should be required (no default)"
```

### Edge Cases
- Handle case where module import fails due to other reasons
- Ensure test isolation - don't modify source files during testing
- Handle Windows path separators in directory checks
