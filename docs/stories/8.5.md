### Technical Considerations
- **Impact Assessment**: Before removing the legacy tools module, identify all dependent files to ensure smooth migration
- **Import Path Changes**: After removal, any code needing tool definitions must import from `docuswarm.tools` (CallableTool2 classes)
- **Backward Compatibility**: This is a breaking change - ensure all consumers are updated before removing the module
- **Testing Strategy**: Run full test suite to catch any missed references or import errors

### Files Likely Affected
- `docuswarm/llm/tools.py` - The legacy module to be removed
- `docuswarm/agents/independent.py` - Likely imports tools for LLM
- `docuswarm/llm/client.py` - May reference legacy tool definitions
- Any test files that mock or import the legacy tools

### Migration Path
```

# After (CallableTool2)
```
