## Dev Notes
- **Architecture**: DualAgentNode is the main coordinator that orchestrates both Independent and Evaluator agents. It follows the pattern from Epic 2 architecture diagram.
- **Context Isolation**: CRITICAL - private_reasoning from Independent Agent MUST NOT reach Evaluator. This is a core design requirement.
- **Iteration Logic**: Basic iteration support. For v1, use simple loop with max 3 iterations. More sophisticated iteration strategies (e.g., exponential backoff, smart feedback summarization) can be added later.
- **State Management**: NodeRunState should contain subject_context, previous_deliverable (if any), and metadata. Each iteration gets fresh state but maintains continuity via previous_feedback.
- **Error Handling**: If Independent Agent fails, do not proceed to Evaluator. If Evaluator fails, return partial result with error indicator.
- **Logging**: Log each phase (Independent start/end, Filter, Evaluator start/end, Iteration decision) with appropriate log levels.
- **Type Safety**: Use TypedDict for output structures, ensure mypy compliance.
