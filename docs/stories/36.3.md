## Story
**As a** pipeline developer,
**I want** the HybridOrchestrator to generate document summaries before pipeline execution starts,
**So that** all pipeline nodes can reuse cached summaries instead of redundantly reading and processing documents, improving performance by ~2.5 seconds per pipeline run.

### Code Changes Required

```python
# Add to HybridOrchestrator class

async def _summarize_referenced_documents(
    self,
    subject_context: dict,
    repo_root: Path,
    session_manager: SessionManager,
    timeout: int = 120,
) -> list[dict]:
    """Run SummaryAgent with timeout protection.
    
    Returns empty list on timeout or error to allow pipeline to continue
    without cached summaries (nodes will use fallback processing).
    """
    try:
        summary_agent = SummaryAgent(
            config=self._config,
            session_manager=session_manager,
            project_root=repo_root,
        )
        result = await asyncio.wait_for(
            summary_agent.summarize_context(subject_context),
            timeout=timeout
        )
        logger.info(
            "documents_summarized",
            count=len(result),
            total_tokens=sum(d.get("llm_tokens_used", 0) for d in result)
        )
        return result
    except asyncio.TimeoutError:
        logger.warning("summary_generation_timeout", timeout_seconds=timeout)
        return []
    except Exception as e:
        logger.error("summary_generation_failed", error=str(e))
        return []
```
