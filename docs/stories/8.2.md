## Dev Notes
- **Dependency Injection**: The `UpdateContextTool` requires a context store instance injected via constructor. This allows for easier testing and follows dependency inversion principles.
- **Operation Semantics**:
  - `set`: Replaces the entire value at the given key
  - `append`: Adds to an existing list or creates a new list if key doesn't exist
  - `remove`: Removes a key from context or removes a value from a list
- **Error Handling**: All exceptions must be caught and returned as `ToolError` with meaningful message and brief description
- **Type Safety**: The Literal type ensures only valid operations are accepted at type-check time
- **SDK Integration**: The tool must implement the CallableTool2 protocol with `name`, `description`, and `params` class attributes
