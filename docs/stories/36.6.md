## Story
**As a** pipeline operator,
**I want** the pipeline resume functionality to properly handle cached document summaries from checkpoints,
**So that** resumed pipelines can continue using pre-computed summaries without re-processing, while gracefully falling back when summaries are unavailable.

## Acceptance Criteria
- [x] Resume works correctly when `docs_context_summary` exists in checkpoint state - the summaries are restored and used by all nodes
- [x] Resume falls back gracefully when `docs_context_summary` is missing from checkpoint (e.g., older pipelines) - uses `.get()` with default empty list
- [x] Warning log is emitted when fallback is used, indicating that summaries are being reconstructed
- [x] Pipeline execution continues without blocking even if summary restoration fails completely
- [x] Context builder receives the restored summaries through `initial_state["docs_context_summary"]` when pipeline resumes

## Dev Notes
- The `resume_pipeline()` method currently reconstructs state from checkpoints - we need to extend this to handle the new `docs_context_summary` field
- If `docs_context_summary` is missing from checkpoint (e.g., pipeline started before EPIC-36), first attempt to query the database for stored summaries using `pipeline_id`
- If DB lookup fails or returns no data, evaluate whether to regenerate summaries based on pipeline criticality - for now, allow pipeline to continue with empty summaries (nodes will use fallback `_resolve_reference_docs()`)
- Use existing `SummaryAgent` class for regeneration if needed, respecting the same 120-second timeout and concurrency limits as the initial pipeline start
- Log levels: `info` for successful restoration, `warning` for fallback usage, `error` for regeneration failures
- Ensure backward compatibility: pipelines created before this story should still resume without errors
- Coordinate with Story 36.5 (PipelineAdapter) to ensure the restored summaries flow correctly through `original_context` to context_builder
- Consider edge case: if checkpoint exists but is corrupted or partially written, treat as missing and use fallback
