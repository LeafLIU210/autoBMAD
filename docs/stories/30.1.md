## Dev Notes
- **测试隔离**: E2E 测试必须在临时目录中运行，使用 `tmp_path` fixture，避免污染真实工作目录
- **Mock 策略**: LLM 调用使用 Mock 响应，返回预定义的测试数据（如分析结果、PRD 内容等）
- **超时设置**: 单个节点执行设置合理超时（建议 30 秒），防止测试挂起
- **验证工具**:
  - 使用 `NodeExecutionContext` 验证节点执行状态
  - 使用 `os.path.exists()` 验证交付物文件生成
  - 使用 `pytest.raises(ContextValidationError)` 验证异常抛出
- **Schema v2 注意**: `task.name` 位于配置根级别，不再是嵌套在 `persona` 中的 `role`
- **权限边界**: 文件工具权限配置位于节点的 `tools.files` 配置中，测试时需加载完整节点配置
- **Token 计算**: 使用 `tiktoken` 库计算 prompt token 数，编码使用 `cl100k_base`
  ```python
  import tiktoken
  enc = tiktoken.get_encoding("cl100k_base")
  token_count = len(enc.encode(system_prompt))
  ```
