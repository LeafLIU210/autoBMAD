## Dev Notes
- The IndependentAgent should now rely entirely on the SDK's auto-dispatch mechanism for tool execution
- The `session.prompt()` method returns an async iterator of wire messages that the MessageAggregator converts to Message objects
- Tool results are automatically handled by the SDK - no manual construction of ToolResult messages needed
- After this change, IndependentAgent's `_call_llm()` should be significantly simplified, focusing only on:
  1. Creating a session via session_manager
  2. Using the session's prompt() method
  3. Feeding wire messages through MessageAggregator
  4. Processing final Message results in _process_message()
- The SDK automatically deserializes tool call parameters using Pydantic models and dispatches to the appropriate CallableTool2 implementation
