# Story 33.2: Add max_deliverables Validation to Validator

## Status

**Status**: Ready for Done

**Last Updated**: 2026-04-07 13:05:43

## Story
**As a** system architect,  
**I want** the Validator to enforce document count constraints based on node configuration,  
**So that** single-document nodes (analyst/pm/ux) cannot create multiple deliverables while multi-document nodes (architect/po) are allowed to create their required document sets.

## Acceptance Criteria
- [x] Validator reads `max_deliverables` from `node.yaml`'s `deliverable.max_deliverables` configuration (default to 1 if not specified)
- [x] Single-document nodes (analyst/pm/ux) fail validation when attempting to create a 2nd deliverable
- [x] Multi-document nodes (architect/po) pass validation when creating multiple deliverables up to their configured limit
- [x] Existing `file_path` and `sha256` validation rules continue to work without regression
- [x] New validation rules run in parallel with existing rules (additive, not replacement)
- [x] Clear error message is returned when max_deliverables constraint is violated
- [x] Integration test verifies end-to-end constraint enforcement for both single and multi-document scenarios

  - `autoBMAD/nodes/*/node.yaml` - Node configurations with max_deliverables

### Implementation Strategy
1. **Layer 1 (Config)**: `NodeDeliverableConfig` must be extended first in `loader.py` to add `max_deliverables: int = 1`
2. **Layer 2 (Validation)**: Add validation rule in `validator.py` that checks deliverable count against config
3. **Layer 3 (Execution)**: Validator reads node config at runtime and enforces constraint

### Backward Compatibility
- Default `max_deliverables = 1` ensures existing single-document behavior is preserved
- New validation is additive - existing rules remain unchanged
- No changes to `NodeResult.deliverable` structure (single-document format unchanged)

### Multi-Document Detection
```python
# Detect if deliverable is multi-document format
if isinstance(deliverable, dict) and deliverable.get("type") == "multi-document":
    document_count = len(deliverable.get("documents", []))
else:
    document_count = 1  # Single document format
```

### Error Message Format
```python
f"Document count constraint violated for node '{node_name}': "
f"attempted {actual_count} documents, but max_deliverables is {max_allowed}"
```

### Key Considerations
- **Prerequisite**: Story 33.1 must be completed first (NodeDeliverableConfig extension)
- **Validation Timing**: Run validation after tool execution but before node completion
- **State Tracking**: Validator needs access to node configuration and current deliverable count
- **Parallel Validation**: Do not short-circuit; collect all validation errors before returning
