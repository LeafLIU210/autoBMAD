## Dev Notes
- CancelledError 是 asyncio 的特殊异常，不应被 Exception 捕获，需单独处理
- 日志级别使用 warning（取消）和 error（异常）区分
- error 消息应包含原始异常信息，便于调试
- duration 计算使用 `time.time() - start_time`，无论成功或失败都需要记录
- 考虑在异常处理中使用 `logger.exception()` 自动包含堆栈信息
- 确保 messages 字段在异常情况下也包含已迭代的消息，供调用方调试
