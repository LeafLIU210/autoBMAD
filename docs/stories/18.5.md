## Dev Notes
- **Module Structure**: Tools should be imported from `docuswarm.tools` module and registered explicitly via `ToolRegistry.register()`
- **Import Path**: Use `from autoBMAD.docuswarm.models.tool_registry import ToolRegistry, ToolDefinition`
- **Auto-registration**: The `register_all_tools()` function should be called at module import time to ensure tools are available
- **Backward Compatibility**: Ensure the ToolRegistry provides the same discoverability that YAML configs provided
- **Error Handling**: If tool registration fails, the system should fail fast with a clear error message
- **Order of Operations**: Tool registration must complete before any agent attempts to use tools
- **Cleanup**: Remove any YAML parsing utilities that were only used for tool loading
