# Story 36.4: Refactor Context Builder to Use Cached Summaries

## Status

**Status**: Ready for Done

**Last Updated**: 2026-04-07 10:39:41

## Story
**As a** pipeline node executor,
**I want** the context builder to use pre-computed document summaries from cache instead of re-reading files from disk,
**So that** node execution is faster and avoids redundant file I/O operations.

## Acceptance Criteria
- [x] Context builder reads from cache when `docs_context_summary` exists in `original_context`
- [x] Falls back to `_resolve_reference_docs()` when cache is missing
- [x] Fallback warning is logged with node_id for observability
- [x] `_resolve_reference_docs()` method is preserved (not deleted) for backward compatibility
- [x] Unit test file `test_context_builder_with_cache.py` is created with comprehensive test coverage
- [x] Info log entry emitted when using cached summaries: `using_cached_docs_summary` with count

## Tasks / Subtasks
- [x] Task 1: Modify `context_builder.build()` to check for `docs_context_summary` in `original_context`

- [x] Task 3: Add info logging for cache hit scenario with document count
- [x] Task 4: Implement fallback path: call `_resolve_reference_docs()` when cache is missing
- [x] Task 5: Add warning logging for fallback scenario

## Dev Notes
- The `docs_context_summary` will be injected into `original_context` by `PipelineAdapter.convert_pipeline_to_node_state()` (Story 36.5)
- Cache structure: `docs_context_summary` is a `list[dict]` containing pre-computed document summaries
- The `build()` method signature may need to remain backward compatible - do not change parameter signatures
- Logging should use structured logging format: `logger.info("using_cached_docs_summary", node_id=node_id, count=len(docs_context))`
- Fallback warning: `logger.warning("missing_cached_docs_summary_using_fallback", node_id=node_id)`
- Ensure the method returns `NodeExecutionContext` with the `docs_context` field populated regardless of cache hit or miss
- This change is part of the larger EPIC-36 optimization to reduce redundant document processing across pipeline nodes
