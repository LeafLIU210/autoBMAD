## Dev Notes
- The dict message format uses `content` field which can be either a string or a list of content blocks
- When content is a list, each block has a `type` field (e.g., "text", "tool_use")
- For tool_use blocks, extract `name`, `input`, and `id` fields
- Use `message.get("content", [])` to safely access content with empty list default
- The `parse_tool_params()` method should already handle the extracted tool_name and params
- Consider adding type guards for content block inspection
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
