## Story

**As a** pipeline execution system,  
**I want** the `IndependentOutputValidationStrategy` to validate outputs from both `create_deliverable` and `submit_execution_report` tool results,  
**So that** the validation layer can properly handle the new execution report format while maintaining backward compatibility with existing deliverable formats.

## Dev Notes

### 当前 `IndependentOutputValidationStrategy` 结构
位置：`autoBMAD/docuswarm/context/validator.py` (lines 557-846)

当前验证字段：
- `deliverable`: `title` (required), `file_path` (required), `sha256` (required), `summary` (optional), `content` (optional), `metadata` (optional)
- `questions`: array of `{priority, question, context}`
- `private_reasoning`: optional string

### `submit_execution_report` 输出格式
```python
{
    "deliverable": {
        "title": str,              # required
        "file_path": str,          # required, non-empty
        "sha256": str,             # required, non-empty
        "content_summary": str,    # optional
    },
    "questions": [                 # optional
        {
            "question": str,       # required
            "priority": str,       # required, enum: blocking/clarifying/optional
            "context": str,        # required
        }
    ],
    "action": str,                 # required, enum: create_deliverable
}
```

### 格式检测策略
使用 `action` 字段存在性作为格式检测标志：
```python
if "action" in data:
    # submit_execution_report 格式 - 完整验证
    self._validate_action(data, result)
    # ... 其他验证
else:
    # create_deliverable 格式 - 原有验证逻辑
    # ... 原有验证
```

### 枚举常量定义
```python
VALID_PRIORITIES: set[str] = {"blocking", "clarifying", "optional"}
VALID_ACTIONS: set[str] = {"create_deliverable"}
```

### 错误代码规范
- `MISSING_ACTION`: action 字段缺失
- `INVALID_ACTION_TYPE`: action 类型非字符串
- `INVALID_ACTION_VALUE`: action 值不在合法枚举中
- `EMPTY_FILE_PATH`: file_path 为空字符串
- `EMPTY_SHA256`: sha256 为空字符串
- `INVALID_CONTENT_SUMMARY_TYPE`: content_summary 类型错误

### 向后兼容性保证
- 不删除或修改现有验证方法的签名
- 新增验证逻辑通过检测新字段触发，不影响旧格式
- 原有 `create_deliverable` 格式的验证路径保持不变
