### 关键代码模式

```python
# 新 Fixture 模式
@pytest.fixture
def mock_session_manager_with_deliverable():
    """返回包含 deliverable 工具调用的消息"""
    manager = AsyncMock()
    manager.single_prompt.return_value = [
        {
            "role": "assistant",
            "content": [
                {"type": "text", "text": "Creating deliverable"},
                {
                    "type": "tool_use",
                    "name": "create_deliverable",
                    "input": {"title": "Analysis Report", "content": "# Analysis"}
                }
            ]
        }
    ]
    return manager
```

### 注意事项
- 不要使用 `patch.dict("sys.modules", {...})` 方式
- 避免使用 `MagicMock` 模拟复杂对象
- 确保 AsyncMock 用于异步方法
- 验证返回值是 dict 而非 Message 对象
