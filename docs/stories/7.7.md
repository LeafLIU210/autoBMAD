## Dev Notes
- **Test Strategy**: Use pytest with `@pytest.mark.asyncio` for async test execution
- **Mocking**: Use `unittest.mock.patch` to mock Kimi SDK Session if needed, but prefer integration test with real API when possible
- **Test Configuration**: Use existing test fixtures for Config and StateManager from `tests/fixtures/`
- **Session Management**: Ensure proper session cleanup with `session_manager.close_all()` in test teardown
- **Node Selection**: Use "analyst" node as it has clear deliverable (analysis report) and evaluation criteria
- **Logging Verification**: Check that structlog output contains keys: `session_id`, `agent_type`, `node_name`, `event`
- **State Verification**: Query StateManager SQLite database to confirm deliverable and evaluation records exist
