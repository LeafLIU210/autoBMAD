## Dev Notes
- 使用 `@dataclass` 装饰器而非 `@dataclass(frozen=True)` 以允许后续可能的修改
- `metadata` 使用 `field(default_factory=dict)` 确保每个实例有独立的字典
- 遵循 EPIC-18 决策: 零向后兼容，完全使用新的函数式模型
- 参考 Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
- 此 dataclass 是其他所有工具的基础，需保持简洁稳定
- 不继承任何基类，保持纯粹的 Python dataclass
