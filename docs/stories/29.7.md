## Dev Notes
- **路径遍历防护实现**: 所有路径必须通过 `os.path.abspath()` 规范化后进行白名单前缀匹配
- **敏感文件列表**: 需拒绝的文件扩展名包括 `.env`, `.env.local`, `.env.production`, `.db`, `.sqlite`, `.sqlite3`, `.key`, `.pem`, `.crt`, `.secret`, `.token`, `.password`
- **错误消息设计**: 越权访问返回统一错误消息 `"Access denied: path outside allowed directories"`，不泄露系统路径信息
- **文件大小检查**: 使用 `os.path.getsize()` 预检查，超过限制时读取前 50000 字符并追加 `[TRUNCATED]` 标记
- **测试隔离**: 使用 `pytest` 的 `tmp_path` fixture 创建临时目录结构，避免污染真实项目文件
- **节点权限配置**: analyst 节点 `allowed_dirs: ["docs/", "docs/research/"]`, po 节点 `allowed_dirs: ["docs/"]`
- **符号链接处理**: 使用 `os.path.realpath()` 解析实际路径后检查白名单
- **性能考虑**: 白名单检查在每次文件操作前执行，确保 O(1) 复杂度
