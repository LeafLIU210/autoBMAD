## Story
**As a** DocuSwarm system architect,  
**I want** to define template configurations for Architect and PO nodes that support multiple document types,  
**So that** these nodes can create the correct number of deliverables (2-4 for Architect, 3-5 for PO) with standardized structure and required sections.

## Context
This story is part of EPIC-33 which implements document creation constraints and multi-document support. The Architect node needs to produce 2-4 related technical documents (system architecture, API design, database schema), while the PO node needs to produce 3-5 product documents (product vision, roadmap, epic list, story list).

Template files have been pre-created at:
- `autoBMAD/docuswarm/templates/architect_templates.yaml`
- `autoBMAD/docuswarm/templates/po_templates.yaml`

## Dev Notes
- Template files are located at `autoBMAD/docuswarm/templates/`
- Existing templates (analyst_templates.yaml, pm_templates.yaml, ux_templates.yaml) serve as format reference
- Template structure must match `NodeDeliverableConfig` expectations in `autoBMAD/nodes/loader.py`
- The `template_id` values should align with `document_type` values used in `CreateDeliverableParams`
- Standards section must reference `_bmad/_memory/tech-writer-sidecar/documentation-standards.md`
- Use Mermaid format for diagrams (specified in standards.diagram_format)
- No time estimates should be included (no_time_estimates: true)

### Template Format Reference
```yaml
version: "1.0"
node_id: <node_name>
description: "Templates description"
templates:
  - template_id: <unique_id>
    title: "Display Title"
    filename_pattern: "file-name.md"
    description: "Template description"
    sections:
      - heading: "Section Name"
        required: true/false
        note: "Optional guidance"
standards:
  style_guide: "path/to/style/guide.md"
  diagram_format: "mermaid"
  no_time_estimates: true
  commonmark_strict: true
```

### Integration Points
- Templates are loaded by `autoBMAD/nodes/loader.py` via `NodeDeliverableConfig`
- Used by `CreateDeliverableTool` for document structure validation
- Referenced by system prompts in `contract_builder.py` for document count guidance
