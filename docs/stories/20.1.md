## Dev Notes
- All new exceptions must inherit from the existing `DocuSwarmError` base class
- The `SDKError` base class should support:
  - `sdk_type`: Optional string to identify the SDK source (e.g., "kimi", "claude")
  - `original_error`: Optional original exception for chaining
  - `context`: Dict for additional debugging information
- Each exception should have sensible default messages
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
- Ensure backward compatibility - existing code should continue to work
- The exception mapping from Kimi SDK:
  - `MaxStepsReached` → `StepLimitExceeded`
  - `RunCancelled` → `SessionCancelled`
  - `ChatProviderError` → `ConnectionError`
  - `InvalidToolError` → `ToolExecutionError`
