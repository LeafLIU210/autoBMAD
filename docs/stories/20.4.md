## Dev Notes

### 异常映射关系

| Kimi SDK 异常 (移除) | DocuSwarm 异常 (新) | 使用场景 |
|---------------------|---------------------|----------|
| `MaxStepsReached` | `StepLimitExceeded` | Agent 执行超过最大步数 |
| `RunCancelled` | `SessionCancelled` | Session 被取消 |
| `ChatProviderError` | `ConnectionError` | API 连接错误 |
| `InvalidToolError` | `ToolExecutionError` | 工具执行失败 |

### 实现示例

```python
# BEFORE: 需要移除
from kimi_agent_sdk import (
    MaxStepsReached,
    RunCancelled,
    ChatProviderError,
    InvalidToolError,
)

try:
    result = await self._session_manager.execute(prompt=prompt)
except MaxStepsReached as e:
    self.logger.warning("max_steps_reached", error=str(e))
    return {"status": "max_steps", "messages": []}
except RunCancelled as e:
    self.logger.info("run_cancelled", error=str(e))
    return {"status": "cancelled", "messages": []}
except ChatProviderError as e:
    raise ConnectionError(f"API error: {e}") from e
except InvalidToolError as e:
    raise ToolExecutionError(f"Tool error: {e}", tool_name=e.tool_name) from e
```

```python
# AFTER: 新实现
from autoBMAD.docuswarm.exceptions import (
    StepLimitExceeded,
    SessionCancelled,
    ConnectionError,
    ToolExecutionError,
    LLMCallError,
)

try:
    result = await self._session_manager.execute(prompt=prompt)
except StepLimitExceeded as e:
    self.logger.warning("max_steps_reached", max_steps=e.max_steps)
    return {"status": "max_steps", "messages": []}
except SessionCancelled as e:
    self.logger.info("run_cancelled", error=str(e))
    return {"status": "cancelled", "messages": []}
except ConnectionError as e:
    self.logger.error("connection_error", error=str(e))
    raise LLMCallError(f"API error: {e}") from e
except ToolExecutionError as e:
    self.logger.error("tool_error", tool_name=e.tool_name)
    raise LLMCallError(f"Tool error: {e}", tool_name=e.tool_name) from e
```

### 技术注意事项

1. **异常链保留**: 使用 `from e` 语法保留原始异常信息，便于调试
2. **日志记录**: 更新日志字段以匹配新的异常属性 (如 `max_steps`)
3. **返回值处理**: `StepLimitExceeded` 和 `SessionCancelled` 返回空列表 `[]` 而不是字典
4. **类型提示**: 更新 `except` 子句中的类型提示
