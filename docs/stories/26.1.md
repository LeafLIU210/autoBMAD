## Story
**As a** developer,
**I want** NodeConfig to have `task`, `runtime`, and `schema_version` fields with properly typed data classes,
**so that** the data model matches what the code actually needs and eliminates the code-configuration gap in `context_builder.py`.

## Acceptance Criteria
1. [x] `loader.py` 新增 `NodeRuntimeConfig` 数据类（`timeout: int`, `retry_max_attempts: int`, `retry_backoff: float`）
2. [x] `NodeConfig` 新增 `schema_version: str`、`task: NodeTaskConfig`、`runtime: NodeRuntimeConfig` 字段
3. [x] `_build_node_config()` 直接解析 v2 格式（无 v1 兼容分支）- 如果 `task` section 不存在，直接抛出配置错误
4. [x] `NodeEvaluatorConfig` 使用 `threshold`（单数）字段名替代 `thresholds`（复数）
5. [x] `context_builder.py` 从 `node_config.task.name` 读取任务名（非 `dict.get` 回退到角色名）
6. [x] 所有 loader、config 相关测试通过
7. [x] `node_config_completeness_checker.py` 将 `task.name`、`task.description` 加入必填检查

@dataclass
class NodeConfig:
    node_id: str
    name: str
    description: str
    sequence: int
    deliverable_type: str
    schema_version: str = "2.0"  # ADD
    task: NodeTaskConfig  # ADD (required)
    runtime: NodeRuntimeConfig  # ADD
    deliverable: NodeDeliverableConfig
    agent: NodeAgentConfig
    questions: NodeQuestionsConfig
    dependencies: NodeDependenciesConfig
    evaluator: NodeEvaluatorConfig | None = None
    persona: dict[str, Any] | None = None

# Add new dataclass (before NodeConfig)
@dataclass
class NodeRuntimeConfig:
    """Configuration for node runtime behavior."""
    timeout: int = 300
    retry_max_attempts: int = 3
    retry_backoff: float = 1.5

@dataclass
class NodeEvaluatorConfig:
