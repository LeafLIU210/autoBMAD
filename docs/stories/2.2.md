## Dev Notes
- **API Provider**: Kimi K2.5 via moonshot.cn API
- **Authentication**: API key via KIMI_API_KEY environment variable
- **Mode Mapping**:
  - Orchestrator → kimi-k2.5-instant (temperature: 0.3, max_tokens: 4096)
  - Independent → kimi-k2.5-agent (temperature: 0.7, max_tokens: 32768)
  - Evaluator → kimi-k2.5-thinking (temperature: 0.5, max_tokens: 8000)
- **Rate Limiting**: Use token bucket algorithm with 200 requests per minute capacity
- **Retry Strategy**: Exponential backoff with base delay of 1 second, max 3 retries, add jitter to prevent thundering herd
- **Error Handling**: Handle 429 (rate limit), 5xx server errors, and timeout exceptions
- **Dependencies**: Use httpx for async HTTP client, structlog for logging
- **Type Safety**: All configuration and response types should use TypedDict or dataclasses
