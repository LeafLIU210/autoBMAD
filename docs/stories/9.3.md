## Story
**As a** developer,
**I want** to resume an interrupted pipeline from its last node,
**So that** users don't lose progress on long-running orchestrations.

## Dev Notes
- **Session ID Format**: Use hierarchical naming `docuswarm-{pipeline_id}-{node_id}` for node-level sessions
- **State Management**: PipelineState must persist `current_node` and `session_id` fields for recovery
- **Error Handling**: Graceful fallback when session not found - restart node from last checkpoint
- **Resume Flow**: First attempt SDK session resume, then decide between continue or restart based on session existence
- **LangGraph Integration**: Use existing checkpoint mechanism to retrieve pipeline state on resume
- **Logging**: Log all resume attempts (success/failure) with structured logging for debugging
- **Partial Results**: Preserve any partial outputs from the interrupted node when resuming

### Key Implementation Details
```python
async def resume_pipeline(self, pipeline_id: str) -> None:
    # 1. Get pipeline state from LangGraph checkpoint
    pipeline_state = await self.state_manager.get_pipeline(pipeline_id)
    last_node = pipeline_state["current_node"]

    # 2. Try SDK session resume
    session = await self.session_manager.resume_session(
        session_id=f"docuswarm-{pipeline_id}-{last_node}"
    )

    if session:
        # 3a. Session exists → continue from interruption point
        result = await self._continue_node(session, pipeline_state)
    else:
        # 3b. Session not found → restart node
        result = await self._restart_node(pipeline_id, last_node)
```
