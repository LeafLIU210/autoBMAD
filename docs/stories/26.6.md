## Dev Notes
- **Task 命名规范**: `task.name` 必须使用动词短语格式（kebab-case），体现"做什么"而非"是谁"。PO 节点的任务是创建史诗和用户故事，故命名为 `create-epics-and-user-stories`
- **最终节点认知**: PO 是 pipeline 的最后一个节点，`memories` 中必须包含"作为最终节点，我的工作成果将直接交付给人类开发团队"这一角色认知
- **与 PM 区分**: PO（Product Owner）聚焦产品愿景和用户价值，PM（Project Manager）聚焦项目执行和资源协调。新建的 `bmm-po.customize.yaml` 必须体现这一差异
- **字段修正**: `evaluator.yaml` 中原来的 `thresholds`（复数）是错误命名，统一改为 `threshold`（单数）以与其他节点保持一致
- **验证命令**: 完成后运行 `python -c "from autoBMAD.nodes.loader import NodeLoader; c = NodeLoader().load('po'); print(c.task.name)"` 应输出 `create-epics-and-user-stories`
