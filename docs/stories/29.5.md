## Dev Notes

### Architecture Context
本 Story 属于 EPIC-29 "SDK 能力激活" 的一部分，专注于四层 System Prompt 架构中的 **Layer 4: Skill Injection**。技能注入器将 BMAD 斜杠命令的描述动态注入到各节点的 system_prompt 中，使 Agent 了解可用的标准化工作流。

### Relevant Source Tree
```
autoBMAD/
├── docuswarm/
│   ├── prompts/
│   │   ├── __init__.py              # 需要导出 SkillInjector
│   │   └── skill_injector.py        # **新建文件 - 本 Story 核心**
│   │   └── template_engine.py       # Story 29.6 实现，调用本注入器
│   └── agents/

.claude/
└── skills/
    ├── agent-analyst/
    │   └── SKILL.md                 # 技能描述源文件
    ├── domain-research/
    │   └── SKILL.md
    ├── market-research/
    │   └── SKILL.md
    └── ... (其他 47 个 BMAD 命令)
```

### Technical Considerations

1. **技能文件路径约定**: `.claude/skills/{command}/SKILL.md`
   - `{command}` 是斜杠命令名（不含 `bmad-` 前缀）
   - `SKILL.md` 文件包含命令的完整说明，前 300 字符用于 prompt 注入

2. **节点技能映射设计**:
   ```python
   NODE_SKILL_MAP = {
       "analyst": ["agent-analyst", "domain-research", "market-research", "advanced-elicitation"],
       "pm": ["agent-pm", "create-prd", "create-epics-and-stories", "validate-prd"],
       "ux": ["agent-ux-designer", "create-ux-design", "advanced-elicitation", "review-edge-case-hunter"],
       "architect": ["agent-architect", "create-architecture", "technical-research", "review-adversarial-general", "check-implementation-readiness"],
       "po": ["create-epics-and-stories", "validate-prd", "check-implementation-readiness", "sprint-planning", "distillator"],
   }
   ```

3. **输出格式示例**:
   ```markdown
   ## 可用 BMAD 技能

   - **agent-analyst**: 激活 Analyst Agent 进行深度需求分析...
   - **domain-research**: 执行领域研究任务，探索业务背景...
   ```

4. **Token 预算控制**:
   - 平均每个技能描述约 200 字符
   - 5 个技能 ≈ 1000 字符 ≈ 250 tokens
   - 预留安全余量，总预算设为 1200 tokens

5. **错误处理策略**:
   - 技能文件不存在 → 跳过该技能，不中断流程
   - 文件读取失败 → 记录警告，返回空描述
   - 无效 node_id → 返回空字符串

- 返回的技能段落将拼接为 system_prompt 的 Layer 4
- 需要与 `IndependentAgent._call_llm_with_prompts` 集成
