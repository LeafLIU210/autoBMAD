## Dev Notes
- The ContextValidator will be called by the node execution flow before any agent execution begins
- Required fields are: `project_description` (str), `requirements` (list or str)
- Optional fields to also validate but not block on: `goals`, `constraints`, `assumptions`
- Hash generation must be deterministic - read file bytes, not parsed JSON, to ensure same file produces same hash
- Consider adding schema validation using pydantic or similar for future extensibility
- The context_hash is critical for context chaining - must match across runs for proper predecessor lookup
- File path validation (existence, readability) should happen before JSON parsing
