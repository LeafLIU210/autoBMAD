## Dev Notes
- **ContextFilter Module**: The filter should be implemented in the nodes/context_filter.py module with a function `filter_for_evaluator(output: IndependentOutput) -> FilteredOutput`
- **Private Fields to Filter**:
  - `private_reasoning`: Internal reasoning notes from the independent agent
  - `tool_call_history`: Record of all tool calls made during execution
  - `internal_notes`: Agent's internal debugging or tracking notes
  - `iteration_feedback`: Feedback from previous iterations (only relevant between iterations)
- **Public Fields to Preserve**:
  - `deliverable`: The main output content (markdown/text)
  - `questions`: Clarifying questions for the evaluator
- **Implementation Approach**:
  - Use dataclasses or Pydantic models for IndependentOutput and FilteredOutput
  - Consider using `exclude` parameter in model serialization
  - Ensure deep filtering - nested private fields should also be removed
- **Test Strategy**:
  - Unit test ContextFilter in isolation with mocked IndependentAgent output
  - Integration test DualAgentNode execution with spy/monitor on evaluator input
  - Use pytest.mark.parametrize for testing multiple private fields
