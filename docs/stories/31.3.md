## Dev Notes
- **File Location**: Create new file at `autoBMAD/docuswarm/prompts/skill_injector.py`
- **SKILL.md Path Convention**: Skills are located at `.claude/skills/{skill-name}/SKILL.md` relative to project root
- **YAML Frontmatter Format**: SKILL.md files use YAML frontmatter between `---` markers with a `description` field
- **Output Format**: Return Markdown string with header "## Available BMAD Skills" followed by bullet list: `- **{skill-name}**: {description}`
- **Truncation Rule**: If description > 150 chars, truncate to 147 and append "..."
- **Empty Whitelist**: Return empty string if whitelist is empty or None
- **Logging**: Use Python's standard `logging` module for warnings about missing/invalid files
- **Static Method**: Method should be `@staticmethod` as it has no instance dependencies
- **Type Hints**: Use proper type annotations: `def build_skills_quick_reference(whitelist: list[str] | None) -> str`
- **Edge Cases to Handle**:
  - Whitelist is None or empty list
  - Skill directory exists but SKILL.md is missing
  - SKILL.md exists but has no YAML frontmatter
  - YAML frontmatter exists but has no `description` field
  - YAML frontmatter is malformed/unparseable
