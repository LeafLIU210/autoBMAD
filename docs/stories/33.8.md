# Story 33.8: System Prompt Guidance for Document Counts

## Status

**Status**: Ready for Done

**Last Updated**: 2026-04-07 13:04:32

## Story
**As a** DocuSwarm system architect,
**I want** the system prompt to dynamically include document count guidance based on each node's `deliverable.max_deliverables` configuration,
**So that** LLM agents understand exactly how many documents they need to create for each node type, preventing constraint violations and ensuring proper multi-document workflow execution.

## Acceptance Criteria
- [x] System prompt dynamically reads `max_deliverables` from node configuration and includes explicit document count guidance
- [x] For single-document nodes (analyst, pm, ux): Prompt clearly states "Create exactly 1 deliverable using create_deliverable tool"
- [x] For multi-document nodes (architect, po): Prompt states "Create {min}-{max} deliverables using create_deliverable tool for each" with specific range
- [x] Guidance is positioned prominently in the system prompt where LLM will notice it before tool invocation
- [x] Unit tests verify prompt content includes correct guidance for both single-doc and multi-doc node types
- [x] Implementation is backward-compatible and does not break existing prompt generation for nodes without `max_deliverables` config

## Dev Agent Record

### Implementation Summary
Story 33.8 implements dynamic document count guidance in system prompts based on each node's `max_deliverables` configuration. The implementation adds a `build_document_count_guidance()` method to `NodePromptContractBuilder` that generates explicit guidance text for LLM agents, helping them understand exactly how many documents they need to create for each node type.

### Key Changes
1. **Added `build_document_count_guidance()` method**: Generates appropriate guidance text based on `max_deliverables` value
   - Single-document nodes (max=1): "Create exactly 1 deliverable"
   - Multi-document nodes: "Create {min}-{max} deliverables" (min calculated as max(2, (max+1)//2))

2. **Updated `_build_instructions_section()`**: Now accepts optional `deliverable_config` parameter and injects document count guidance at the beginning of the instructions section for maximum LLM visibility.

3. **Added `_load_deliverable_config()` helper**: Loads node configuration to extract deliverable settings for guidance generation.

4. **Updated `build_independent_contract()`**: Now loads deliverable config and passes it to instructions section builder.
