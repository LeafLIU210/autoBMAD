## Status

**Status**: Ready for Done

## Story
**As a** system,
**I want** `pipeline/graph.py` to use `node_execution/executor.py` for actual node execution,
**So that** the DualAgentNode is invoked during pipeline runs and produces real deliverables instead of empty placeholders.

## Acceptance Criteria
- [x] `create_pipeline_graph()` accepts optional `session_manager` parameter of type `KimiSessionManager | None`
- [x] When `session_manager` is provided, uses `_create_integrated_node_executor()` to create node executors
- [x] When `session_manager` is `None`, falls back to existing `_create_default_node_executor()` for backward compatibility
- [x] `_create_integrated_node_executor()` calls `create_node_executor()` from `node_execution.executor` module
- [x] State conversion implemented: PipelineState → NodeRunState → PipelineState
- [x] `orchestrator.py` passes session_manager when invoking `create_pipeline_graph()`
- [x] File output via `FileStorage.save_deliverable()` after successful node execution

## Dev Notes
- **State Conversion Fields**: PipelineState contains `pipeline_id`, `subject_context`, `completed_nodes`, `deliverables`, `questions`, `evaluation_history`, `node_iterations`. NodeRunState contains `run_id`, `context_file`, `task`, `chained_context`, `deliverable`, `questions`, `evaluation`, `iteration`, `max_iterations`, `status`.
- **Backward Compatibility**: The existing `_create_default_node_executor()` must remain functional for unit tests and scenarios where no LLM session is available. Add a deprecation warning log when falling back to default executor.
- **Import Handling**: Use lazy import inside `_create_integrated_node_executor()` to avoid circular imports: `from autoBMAD.docuswarm.node_execution.executor import create_node_executor`
- **Pipeline Nodes**: The graph uses PIPELINE_NODES = ["analyst", "prd", "ux_design", "architecture", "epics_stories"]
- **Orchestrator Flow**: Ensure session_manager is created before pipeline graph creation and persists across node executions
- **Error Handling**: If node execution fails, convert the error state back to pipeline state format and propagate appropriately
