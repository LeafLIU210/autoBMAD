## Story
**As a** system,
**I want** the IndependentAgent prompt to instruct the LLM to use the `create_deliverable` tool,
**So that** the LLM produces deliverables via tool calls instead of returning inline JSON.

## Dev Notes
- **File Location**: The prompt is defined in `autoBMAD/docuswarm/agents/independent.py` as part of the `IndependentAgent` class
- **SDK Compatibility**: The Kimi Agent SDK supports mixed tool calls + text output, so structured questions can be returned alongside tool invocations
- **Backward Compatibility**: This change only affects the response format, not the core agent logic
- **Error Prevention**: The prompt should clearly differentiate between deliverable content (via tool) and questions/feedback (via structured return)
- **Token Efficiency**: Tool-based file writing may affect token usage; monitor for unexpected cost increases

### Prompt Change Reference
```
BEFORE:
  ## Response Format
  Respond with valid JSON:
  {"deliverable": {...}, "questions": [...], "private_reasoning": "..."}

AFTER:
  ## Deliverable Output
  You MUST use the 'create_deliverable' tool to save your deliverable document.
  Do NOT return deliverable content in JSON format — use the tool to write files.

  After creating your deliverable via the tool:
  1. Generate follow-up questions (blocking, clarifying, optional)
  2. Return a summary of what you created and your questions
```

### Technical Considerations
- The system prompt modification should be atomic and well-commented for future maintenance
- Consider adding a version comment to track when this change was made
- The LLM may need a few iterations to adapt to the new behavior; be prepared for potential prompt refinement
