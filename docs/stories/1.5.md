## Dev Notes
- **Database Integration**: StateManager depends on `storage/database.py` (Story 1.4) for SQLite connection. The database must have WAL mode enabled and the `node_runs` table created.
- **JSON Handling**: All complex fields (deliverable, questions, evaluation, answers, chained_context) are stored as JSON strings. Use Python's `json` module with default serialization.
- **Context Hashing**: Use SHA-256 hash of the context file content for context_hash. This enables grouping related node runs.
- **Context Chaining**: The `get_chained_deliverables` method should query the database for completed runs with matching `context_hash` but different `node_id`. The execution order is: analyst → pm → ux → architect → po.
- **Error Handling**: Raise `StorageError` (from exceptions.py) for all database-related errors with descriptive messages.
- **Transaction Isolation**: Each public method should handle its own transaction unless explicitly composing multiple operations.
