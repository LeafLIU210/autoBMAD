## Dev Notes
- The ContextChainer uses the node SEQUENCE: `["analyst", "pm", "ux", "architect", "po"]`
- Predecessors are determined by index position in SEQUENCE array
- Context hash is used to match runs - only successful runs (status="completed") should be queried
- Deliverables are stored with keys like `analyst_deliverable`, `pm_deliverable`, etc.
- If no_chain=True, return empty dict - caller handles empty chained context
- Missing predecessor runs should log a warning but NOT block execution
- The state_manager must have `get_latest_successful_run(node_id, context_hash)` method
- Consider adding caching for repeated calls within same execution context
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
