## Story
**As a** system administrator,
**I want** to configure shared_context permissions per node via node.yaml files,
**So that** I can control which nodes are allowed to update shared context and what operations they can perform.

## Dev Notes
- **Important**: This story has a dependency on Story 35.3 (`NodeSharedContextConfig` dataclass implementation). The dataclass must exist in `autoBMAD/nodes/loader.py` before this configuration can be parsed.
- **Correct Path**: All modifications must be made to files in `autoBMAD/nodes/*/` directory. The `nodes/*/` directory (without `autoBMAD/`) is deprecated and should not be modified.
- **Configuration Structure**: The `tools.shared_context` section should be added under the existing `tools:` section in each node.yaml file.
- **Default Behavior**: When `shared_context` section is absent, nodes should default to `enabled: true` with all operations allowed, using the global whitelist.
- **Per-Node Whitelist**: The `allowed_keys` field is optional. When present, it merges with (not replaces) the global whitelist.
- **Global Whitelist Reference**: Current global whitelist includes: `facts.*`, `decisions.*`, `open_questions`, `doc_summaries.*`, `notes`

### Example Configuration
```yaml
tools:
  # ... existing tools config ...
  shared_context:
    enabled: true
    operations: ["set", "append", "remove"]
    # Optional: per-node whitelist override (default: uses global whitelist)
    # allowed_keys:
    #   - "facts.*"
    #   - "decisions.*"
```
