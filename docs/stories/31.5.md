## Story
**As a** DocuSwarm system architect,  
**I want** the IndependentAgent to automatically inject whitelisted BMAD skills into its system prompt,  
**So that** Claude can see available skills in the quick reference and make informed decisions about which skills to invoke during task execution.

## Acceptance Criteria
- [x] System prompt contains "## Available BMAD Skills" section when `quick_reference_enabled` is true
- [x] Section contains only whitelisted skills for that specific node (filtered by `tool_permissions.skills.whitelist`)
- [x] Quick reference is appended after Layer 3 (task section) and before the final system prompt
- [x] Skill descriptions are truncated to 150 characters max to prevent context overflow
- [x] Integration test passes end-to-end verifying the complete flow from node config to LLM call
- [x] Gracefully handles cases where SkillInjector returns empty or fails (no crash, just skip injection)

## Dev Notes
- **Integration Point**: This story depends on Story 31.3 (SkillInjector implementation) - ensure `SkillInjector` class exists in `autoBMAD/docuswarm/prompts/skill_injector.py`
- **Node Config Access**: The `IndependentAgent` receives node configuration via `self.node.tool_permissions` - skills config is nested at `tool_permissions.skills`
- **System Prompt Layers**: 
  - Layer 1: Base system prompt (agent persona)
  - Layer 2: Context files
  - Layer 3: Task section (this is where quick reference should be appended AFTER)
  - Layer 4: Final system prompt append (skills quick reference goes here)
- **Error Handling**: If `SkillInjector` fails or returns empty string, log warning and continue without skills section - do not crash the agent
- **Performance**: Skills quick reference should be built only once per node execution, not per LLM call
- **Backward Compatibility**: Nodes without `tools.skills` config should continue to work without any skills section in the prompt
- **Context Size**: Monitor total context size - if whitelist has many skills, consider limiting to top N most relevant

1. **Import Added**: `from autoBMAD.docuswarm.prompts.skill_injector import SkillInjector`
2. **Node Config Loading**: Uses `NodeLoader.load(self.node_id)` to get node configuration
3. **Skills Config Check**: Validates `skills_config.quick_reference_enabled` and `skills_config.whitelist`
4. **Quick Reference Build**: Calls `SkillInjector.build_skills_quick_reference(whitelist)`
5. **Prompt Appending**: Appends skills section to `system_prompt_append`
6. **Error Handling**: Wrapped in try/except with logging for graceful degradation
