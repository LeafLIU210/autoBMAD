## Dev Notes
- **Test File Location**: `tests/test_tool_permissions.py` (new file)
- **PathValidator Integration**: Tests should verify the 4-layer security defense is working:
  - Layer 1: Directory whitelist + symlink resolution + prefix matching
  - Layer 2: File type restrictions (extension whitelist/blacklist)
  - Layer 3: Directory pattern blocking (.git, .env, node_modules, __pycache__)
  - Layer 4: Application-level checks (binary detection, encoding validation)
- **Node Configuration**: Tests should load actual node.yaml files from `autoBMAD/nodes/` to verify real configuration
- **Test Data Setup**: Create temporary test files in `docs/` for read/list tests; attempt access to sensitive files outside allowed dirs
- **EvaluatorAgent Verification**: Check that EvaluatorAgent's `tools` config is empty or None
- **Security Boundaries**: Tests should confirm that:
  - `docs/research/` files ARE accessible (cross-directory within allowed root)
  - Files in `.env`, `.git/`, project root config files are NOT accessible
- **Dependencies**: This story depends on Stories 34.1-34.5 (node.yaml configuration updates) being complete
