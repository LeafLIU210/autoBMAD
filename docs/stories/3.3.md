## Dev Notes
- The graph follows a simple linear flow: START → {node_id} → END
- SqliteSaver requires langgraph.checkpoint.sqlite to be installed
- Thread isolation uses run_id as thread_id in configurable section
- State schema (NodeRunState) must be imported from state.py
- Node executor function created via create_node_executor factory
- Graph should be compiled with checkpointer before execution
- Database path defaults to "docuswarm.db" but should be configurable
- SqliteSaver requires a pre-opened SQLite connection with check_same_thread=False

### Dependencies
- Requires: Story 3.1 (NodeRunState schema defined)
- Requires: Story 3.4 (Node executor function created)

### Technical Considerations
- SqliteSaver requires a pre-opened SQLite connection
- Thread configuration format: `{"configurable": {"thread_id": run_id}}`
- StateGraph requires TypedDict for state schema
- Node execution function must be async-compatible
