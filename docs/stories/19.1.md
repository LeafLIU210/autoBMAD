## Dev Notes
- **Critical**: The old `mock_kimi_sdk` fixture uses `autouse=True` which automatically applies to ALL tests, causing potential side effects and making tests order-dependent
- **Migration Pattern**: Replace complex Kimi SDK mocks with simple AsyncMock objects that return standard dict format
- **Return Format**: New fixtures should return dict lists (e.g., `[{"role": "assistant", "content": "..."}]`) instead of Kimi SDK Message objects
- **SDKResult Import**: The `mock_sdk_result` fixture needs to import `SDKResult` from `autoBMAD.docuswarm.llm.response`
- **Backward Compatibility**: After removing global mock, individual tests may need updates if they relied on the implicit mock
- **Test Execution Order**: Run tests in isolation first (`pytest -v -x`) to catch any issues with individual test files
- **Code Review**: Ensure no imports of `kimi_agent_sdk` remain in test files after migration
