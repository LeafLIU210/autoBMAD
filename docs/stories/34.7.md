### Current System Prompt Structure
The IndependentAgent currently builds system prompts via two paths:
1. **Legacy path**: `_format_system_prompt()` - Combines persona + hardcoded agent instructions
2. **Contract path**: `_format_system_prompt_with_contract()` - Uses NodePromptContractBuilder

The contract path is the P0 standard and should be the primary integration point.

### Tool Configuration Context
From the Epic and NodeLoader:
- All 5 nodes (analyst, pm, ux, architect, po) have unified tool configuration:
  ```yaml
  tools:
    allowed_builtin_tools: ["Read", "Glob"]
    file_permissions:
      allowed_read_dirs: ["docs/"]
    search_permissions:
      search_dirs: ["docs/"]
  ```
- The IndependentAgent already receives tool permissions via `execute_with_input()` (lines 819-850)

### Proposed Tool Section Format
```markdown
## Available Tools

You have access to the following tools for document operations:

- **read_document**: Read file content from allowed directories
  - Use to access context files in docs/ and subdirectories
- **list_documents**: List files in a directory
  - Use to explore available files before reading
- **grep_search**: Search for patterns in files
  - Use to find specific content across multiple files
- **glob_search**: Find files matching a pattern
  - Use to locate files by name patterns (e.g., "*.md")
- **create_deliverable**: Create output document
  - Use to save your final deliverable (already described in Agent Instructions)

**File Access**: You can only access files within the `docs/` directory and its subdirectories.
```

### Important Considerations
1. **Avoid Duplication**: The `create_deliverable` tool is already extensively documented in the Agent Instructions section (lines 148-227). The tool awareness section should reference this, not duplicate it.
2. **Layer Placement**: Per Four-Layer Architecture (Story 29.6):
   - Layer 1: claude_code preset (SDK handles)
   - Layer 2: Persona (already in contract)
   - Layer 3: Task Context + Tools (recommended for tool awareness)
   - Layer 4: Skills
3. **Dynamic Content**: Tool availability varies by node configuration. The section should only appear when `allowed_builtin_tools` is configured.
