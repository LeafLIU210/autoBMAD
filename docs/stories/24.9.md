## Dev Notes

### Performance Targets Summary
| Metric | Target | Threshold |
|--------|--------|-----------|
| Single iteration | < 60s | 60s hard limit |
| Complete node (3 iter) | < 180s | 180s hard limit |
| State update | < 100ms | 100ms hard limit |
| File save | < 50ms | 50ms hard limit |

### Technical Considerations
- Use `pytest-benchmark` plugin for consistent measurement
- Mock LLM calls to avoid external API variability
- Run benchmarks in isolated environment
- Warm up JIT/cache before measurement
- Take median of multiple runs, not average

### Benchmark Environment
- Python 3.11+
- pytest with pytest-benchmark
- In-memory state for state tests
- Temporary directory for file tests
- No network I/O during measurements

### Known Variables to Control
- CPU load from other processes
- Memory pressure
- Disk I/O speed
- Python interpreter warmup
