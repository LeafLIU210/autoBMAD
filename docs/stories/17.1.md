## Dev Notes
- Kimi SDK Message 类使用 `.role` 和 `.content` 属性访问，dict 格式使用 `msg.get("role")` 和 `msg.get("content")` 方法
- `MessageAggregator` 是 Kimi SDK 特有的流式处理组件，在 Claude SDK 中不需要
- ToolResultExtractor 新增 `extract_from_dicts()` 方法替代原有的 `extract_from_messages()` 方法处理 dict 格式
- 需要处理 `content` 字段的多种类型：可能是 `str` 或 `list`（包含 text 和 tool_use blocks）
- 异常 `MaxStepsReached` 和 `RunCancelled` 将在 Story 20 中处理，暂时保留但标记为待移除
- 新增 `_convert_messages_to_dicts()` 方法将 Kimi SDK Message 对象转换为 dict 格式
