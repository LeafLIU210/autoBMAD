## Dev Notes
- EscalationHandler requires StateManager dependency for updating node run status
- Use structlog for logging with component="EscalationHandler"
- Escalation records should be stored in memory (Dict) for runtime access
- Node run status updates use: `await state_manager.update_node_run_status(run_id, status)`
- Node run answers updates use: `await state_manager.update_node_run_answers(run_id, key, value)`
- The escalate() method is called from DualAgentNode when verdict is "BLOCKED"
- After resolution, the node will re-execute with the user guidance in context
- Consider storing escalations in database for persistence across restarts (future enhancement)
