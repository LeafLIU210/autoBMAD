## Dev Notes
- The `AuditEvent` dataclass should use `datetime` for timestamps and store them in ISO format in reports
- Event types should be limited to: "context_build", "filter", "violation"
- The logger should use structlog for consistent structured logging throughout the codebase
- Events should be stored in memory for report generation; consider future persistence options
- The `generate_report()` method should calculate isolation_status as "CLEAN" if no violations, "VIOLATION" otherwise
- Context keys should be logged to verify which fields each agent received
- Fields removed during filtering should be explicitly logged for compliance verification
- Violations should include type (e.g., "private_field_leak", "unauthorized_access") and details for debugging
- Follow Ralph's principles: DRY, KISS, YAGNI, Occam's Razor
