## Dev Notes
- The `mode` and `yolo` parameters are retained for backward compatibility but are ignored (SDK uses default behavior)
- Internal `ClaudeSDKWrapper` handles all SDK interactions including environment variables
- Tool descriptions are formatted as "- {tool.name}: {tool.description}" for each tool
- If tools list is None or empty, the original prompt is passed directly to `single_prompt`
- Default timeout is 1800.0 seconds (30 minutes)
- Default agent_name is "docuswarm"
- The class uses structlog for logging with component="SessionManager"
