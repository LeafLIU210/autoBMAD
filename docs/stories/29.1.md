## Dev Notes

### 技术设计
- **MCP Server 架构**: 使用 `claude_agent_sdk.mcp.server.FastMCP` 创建轻量级 MCP 服务器
- **路径安全策略**:
  ```python
  def validate_path(request_path: str, allowed_dirs: list[str]) -> str:
      abs_path = os.path.abspath(request_path)
      abs_allowed = [os.path.abspath(d) for d in allowed_dirs]
      if not any(abs_path.startswith(d) for d in abs_allowed):
          raise PathNotAllowedError(f"Path {request_path} not in allowed directories")
      return abs_path
  ```
- **文件大小处理**: 读取后检查长度，超过 50000 字符则截断为 50000 并追加 `"\n\n[文件已截断 - 超过50000字符限制]"`

### 接口定义
```python
@tool
def read_document(path: str) -> str:
    """
    Read the content of a document within allowed directories.
    Args:
        path: Relative or absolute path to the file
    Returns:
        File content or error message
    """

@tool
def list_documents(directory: str, recursive: bool = False) -> list[str]:
    """
    List all documents in an allowed directory.
    Args:
        directory: Directory path to list
        recursive: Whether to include subdirectories
    Returns:
        List of file paths
    """
```

### 安全注意事项
- 始终使用 `os.path.abspath()` 而非简单的字符串拼接
- 白名单匹配使用 `str.startswith()` 确保目录边界（加 `os.sep` 防止部分匹配）
- 禁止访问的文件模式：`.env`, `*.db`, `*.sqlite`, `.git/`, `node_modules/`
- 错误消息不暴露文件系统结构，仅返回配置的白名单目录

### 依赖项
- `claude_agent_sdk.mcp.server.FastMCP` - MCP 服务器框架
- `pathlib.Path` - 现代化路径处理
- `os.path` - 路径规范化
