## Dev Notes
- **Dependencies**: Requires `structlog` for logging, `copy` for deep copy operations
- **File Location**: `docuswarm/context/filter.py`
- **Class to Implement**: `ContextFilter`
- **Key Methods**:
  - `filter_for_evaluator(independent_output: Dict[str, Any]) -> Dict[str, Any]` - Main filtering entry point
  - `_remove_nested_private(data: Any) -> Any` - Recursive nested field removal
  - `_remove_markers(data: Any) -> Any` - Remove markers from strings
- **Constants**:
  - `FIELDS_TO_REMOVE`: List of field names to filter out
  - `MARKERS_TO_REMOVE`: List of string markers to strip
- **Edge Cases**:
  - Empty dictionaries/lists should pass through unchanged
  - None values should be preserved
  - Non-dict/list values (int, bool, float) should pass through
  - Deeply nested structures should be handled
- **Logging**: Use `structlog.get_logger().bind(component="ContextFilter")`
- **Error Handling**: No exceptions expected - filtering should be silent
- **Performance**: Use deep copy only once at entry point, not per recursion
