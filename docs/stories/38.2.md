## Dev Notes
- **Schema Location**: `EVALUATOR_OUTPUT_SCHEMA` 应定义在 `autoBMAD/docuswarm/agents/evaluator_config/schemas.py` 模块级别，与现有的 `CriteriaWeights`、`EvaluationCriteria` 等类型放在一起
- **Type Import**: 需要添加 `from typing import Any` 以支持 `dict[str, Any]` 类型注解
- **Enum Alignment**: 必须与 `agents/evaluator.py` 中硬编码的 verdict 字符串完全一致（大小写敏感）
- **Numeric Constraints**: `minimum: 0.0` 和 `maximum: 1.0` 与评分系统的语义一致，确保所有分数都在有效范围内
- **Dynamic Keys**: `criterion_scores` 使用 `additionalProperties` 而非固定 `properties`，因为 criteria 是动态配置的
- **No Breaking Changes**: 这是一个纯新增常量，不影响现有代码逻辑
