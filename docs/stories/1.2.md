## Dev Notes
- Use `@dataclass` decorator for the Config class with `frozen=True` for immutability
- Configuration precedence: environment variables > YAML file > hardcoded defaults
- Load order: `.env` first (required), then `config/docuswarm.yaml` (optional)
- Raise `ConfigurationError` with clear message when KIMI_API_KEY is missing or empty
- Consider adding validation for numeric ranges (e.g., approval_threshold between 0 and 1)
- Store config instance as module-level singleton for easy access
- Use `field(default_factory=...)` for mutable defaults like lists/dicts
- Consider adding config reload capability for development mode
- YAML config should support dot-notation access via SimpleNamespace if desired

### Technical Implementation Details
- Required packages: python-dotenv, pyyaml
- Config dataclass fields should match the Epic schema exactly
- Add `__post_init__` method for validation after instantiation
- Consider using Pydantic as alternative for more complex validation needs
