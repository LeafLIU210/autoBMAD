## Dev Notes

### Implementation Details
The implementation resides in `autoBMAD/nodes/loader.py` and extends the existing node configuration system:

**Source Location**: `autoBMAD/nodes/loader.py`
- `NodeSharedContextConfig` dataclass: lines 144-159
- `NodeToolPermissions` extension: line 181
- Parsing logic in `_build_node_config`: lines 479-513

**Configuration Schema** (node.yaml `tools.shared_context` section):
```yaml
tools:
  shared_context:
    enabled: true                    # Optional, default: true
    operations: ["set", "append"]    # Optional, default: ["set", "append", "remove"]
    allowed_keys:                    # Optional, default: null (uses global whitelist)
      - "facts.*"
      - "decisions.*"
```

**Key Implementation Points**:
1. **Default Behavior**: When `tools.shared_context` is absent, defaults ensure backward compatibility
2. **allowed_keys Semantics**:
   - `None` → use global whitelist from `update_context.py`
   - `[]` (empty) → no keys allowed (most restrictive)
   - `["pattern.*"]` → merge with global whitelist (per-node additions)
3. **Operations**: Valid values are `"set"`, `"append"`, `"remove"`; invalid values should be validated
