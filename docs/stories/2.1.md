## Dev Notes
- Use `abc.ABC` as base class for abstract functionality
- Use `@abstractmethod` decorator on methods that subclasses must implement
- Import `AgentConfig` and `LLMClient` from their respective modules (will be created in other stories - use TYPE_CHECKING imports to avoid circular dependencies)
- Use `structlog.get_logger()` for consistent logging across all agents
- Bind logger with agent class name for traceability: `self.logger = structlog.get_logger().bind(agent=self.__class__.__name__)`
- Follow Ralph's principles: Keep it simple, avoid premature abstraction
- Consider adding a `@property` for node_id if needed by subclasses
- The BaseAgent should be minimal - only shared functionality that ALL agents need
