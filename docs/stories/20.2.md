## Dev Notes
- **Import Path**: Use `from autoBMAD.docuswarm.exceptions import ...` (not `from docuswarm.exceptions`)
- **Return Type Change**: The method now returns `list[dict[str, Any]]` instead of `list[Message]` since Message format was migrated in Epic 17
- **SDK Wrapper**: The `session_manager.py` now uses `self._sdk_wrapper.execute(prompt)` instead of `session.prompt(prompt)`
- **Exception Mapping**:
  - `MaxStepsReached` → `StepLimitExceeded` (with `max_steps` context)
  - `RunCancelled` → `SessionCancelled`
  - `ChatProviderError` → `ConnectionError` (wrapped in `LLMCallError`)
  - `ConfigError` → `ConfigurationError` (re-raised)
  - `InvalidToolError` → `ToolExecutionError` (re-raised)
- **Graceful Handling**: `StepLimitExceeded` and `SessionCancelled` return empty list `[]` instead of raising
- **Logging**: Each exception handler includes appropriate logging with structured log keys
- **Exception Chaining**: Always use `raise ... from e` to preserve the original exception context
- **Context Preservation**: The new exceptions support context dictionaries that can be used for debugging
