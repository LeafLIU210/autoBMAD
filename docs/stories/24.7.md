- Context accumulation follows a cumulative pattern: each node receives its predecessor's deliverables in addition to subject_context
- Node types and their context requirements:

  - **pm**: subject_context + analyst_deliverable
  - **ux**: subject_context + analyst_deliverable + pm_deliverable
  - **architect**: subject_context + analyst_deliverable + pm_deliverable + ux_deliverable
  - **po**: subject_context + all four predecessor deliverables
- Use mocked PipelineState to simulate different scenarios with predecessor deliverables available
- Test both success cases and edge cases (missing predecessors should not cause errors)
