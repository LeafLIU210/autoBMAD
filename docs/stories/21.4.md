## Dev Notes
- The NodeLoader class must maintain backward compatibility with existing node.yaml files that do not contain the new `task` block
- The `task` field in NodeConfig should be optional (None when not present in YAML)
- The deliverable config should accept new fields template_title and output_filename with empty string defaults
- Optional files (evaluator.yaml, persona.json) should be loaded only when present
- Use yaml.safe_load() for secure YAML parsing
- Follow existing error handling patterns (raise NodeLoadError for missing required files)
- All file operations must use UTF-8 encoding
