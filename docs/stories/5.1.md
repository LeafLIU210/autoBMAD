## Dev Notes
- Default thresholds: approval=0.70, escalation=0.50
- Node-specific overrides stored in QualityConfig.NODE_THRESHOLDS dict
- Architect node uses stricter thresholds: approval=0.75, escalation=0.55
- VerdictDeterminer uses max_iterations=3 by default but accepts parameter
- Configuration should be loadable from config.yaml or environment variables
- Follow Ralph's principles: DRY (use class methods), KISS (simple if/else logic), YAGNI (only needed verdicts)
- Use dataclasses for immutable threshold configurations
- Import typing.Dict for type hints (Python 3.9+ can use dict[str, QualityThresholds])
