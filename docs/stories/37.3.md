# Story 37.3: Update PipelineAdapter for Summary Propagation

## Status

**Status**: Ready for Done

**Last Updated**: 2026-04-07 09:32:20

## Story
**As a** pipeline developer,
**I want** the PipelineAdapter to propagate `docs_context_summary` from PipelineState into NodeRunState,
**So that** the context builder can use cached document summaries instead of rebuilding them from disk for each node execution.

## Acceptance Criteria
- [x] `docs_context_summary` from PipelineState is injected into `original_context` when present
- [x] When PipelineState has no `docs_context_summary`, `original_context` remains unchanged (backward compatibility)
- [x] The serialized `context_file` includes the `docs_context_summary` data for downstream consumption
- [x] The implementation preserves all existing PipelineAdapter functionality
- [x] Unit tests verify the adapter correctly propagates the summary to NodeRunState

## Tasks / Subtasks

- [x] Task 3: Ensure backward compatibility - when summary is missing, use subject_context unchanged
- [x] Task 4: Verify that `serialize_context()` includes the summary in the serialized output

## Dev Notes
- **Target File**: `autoBMAD/docuswarm/node_execution/pipeline_adapter.py`
- **Key Method**: `convert_pipeline_to_node_state()` - static method that converts PipelineState to NodeRunState
- **Implementation Pattern**:
  ```python
  docs_summary = pipeline_state.get("docs_context_summary", [])
  if docs_summary:
      original_context = {**subject_context, "docs_context_summary": docs_summary}
  else:
      original_context = subject_context
  ```
- **Dependencies**: Requires Story 37.1 (PipelineState schema update) and Story 37.2 (create_initial_state update) to be completed first
- **Integration Point**: This change enables context_builder.build() to check for `docs_context_summary` in `original_context` (implemented in Story 37.4)
- **Performance Impact**: Eliminates ~500ms per node by avoiding redundant disk reads for document resolution
- **Type Safety**: Ensure type hints remain consistent with `list[dict[str, Any]]` for the summary field
- **Logging Consideration**: Consider adding debug logging when summary is propagated (optional enhancement)
