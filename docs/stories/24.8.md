## Dev Notes

### Technical Considerations
- Use `unittest.mock` to mock LLM API calls for deterministic testing
- Use `pytest` with `pytest.mark.parametrize` for multiple test cases
- Use `tempfile` for creating isolated test work directories
- Use `time.time()` for performance measurements
- Ensure all file operations use atomic writes for consistency

### Dependencies
- Requires DualAgentNode implementation from EPIC-21/22/23
- Requires PipelineState implementation
- Requires FileStorage implementation
- Requires context accumulation logic

### Key Test Components
1. **Session Manager**: Manages pipeline lifecycle and state
2. **PipelineState**: Tracks execution state, deliverables, and node status
3. **DualAgentNode**: Executes individual nodes with dual-agent pattern
4. **FileStorage**: Handles deliverable file persistence
5. **Context Accumulator**: Builds context for each node

### Test File Location
- Primary test file: `tests/integration/test_e2e_node_execution.py`
- Test data location: `tests/fixtures/`
- Use relative imports within tests directory

### Mock Strategy
- Mock `IndependentAgent.execute` to return predefined outputs
- Mock `EvaluatorAgent.execute` to return configurable verdicts
- Mock file I/O operations for isolation
- Use `unittest.mock.patch` for context managers

### Performance Measurement
- Use `time.perf_counter()` for high-precision timing
- Run each benchmark multiple times and take median
- Separate setup time from execution time
- Log detailed timing information for debugging
