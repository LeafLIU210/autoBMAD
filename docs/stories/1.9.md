## Dev Notes
- **Library Choice**: Use `structlog` for structured logging as specified in Epic - it provides better JSON serialization and context handling than standard logging
- **Configuration Priority**: Environment variable `LOG_LEVEL` takes precedence over config file; sensible default is "INFO"
- **Context Isolation**: Each node execution should have isolated logging context to track run_id across async boundaries
- **Sensitive Data**: Implement a filter processor to redact API keys, passwords, and tokens from log output
- **Performance**: Use lazy string evaluation to avoid expensive string formatting when log level is disabled
- **File Rotation**: Use `logging.handlers.RotatingFileHandler` for log file rotation (10MB default, 5 backup files)
- **Async Compatibility**: Structlog 24+ supports asyncio natively via contextvars; ensure Python 3.14 compatibility
- **Colors**: Console output should use Rich colors but JSON output should be plain
