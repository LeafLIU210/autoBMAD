## Dev Notes
- **Backward Compatibility**: The default value of empty string `""` ensures that old persona.json files without this field will continue to load without errors
- **Field Placement**: The communication_style field should be placed after identity and before expertise for logical grouping
- **Type Safety**: Using `str` type with empty string default is simple and effective; no need for Optional[str] since empty string is a valid "no style specified" value
- **Serialization**: The field should serialize to JSON as an empty string when not specified, matching the default
- **Related Stories**: This change enables Story 22.2 (_format_persona_section) to include the communication style in system prompts
- **BMM Alignment**: This field maps to the <communication_style> block in _bmad/bmm/agents/*.md files
