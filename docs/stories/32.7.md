# Story 32.7: Integrate skill_ref into IndependentAgent

## Status

**Status**: Ready for Done

**Last Updated**: 2026-04-07 10:35:28

## Story
**As a** system architect,  
**I want** the IndependentAgent to automatically include skill invocation hints in the system prompt when a node's task has a `skill_ref` configured,  
**So that** Claude Code can leverage the appropriate BMAD skills during node execution, improving task completion quality and consistency across the pipeline.

## Acceptance Criteria
- [x] System prompt references the skill when `skill_ref` is configured in the node's task configuration
- [x] Skill hint is clear and actionable for Claude (format: "Use the `{skill_ref}` skill to complete this task.")
- [x] Nodes without `skill_ref` configured continue to work without errors (backward compatibility)
- [x] The skill_ref value is read from `node_config.task.skill_ref` during prompt construction
- [x] Skill hint appears in the correct location within the system prompt (before user instructions)

## Tasks / Subtasks
- [x] Task 1: Modify `IndependentAgent._build_system_prompt()` to accept `node_config` parameter and extract `skill_ref`
- [x] Task 2: Add skill invocation hint logic: when `skill_ref` is present, append skill hint to system prompt
- [x] Task 3: Ensure graceful handling when `skill_ref` is `None` or missing (no hint added, no errors)
- [x] Task 4: Update any calling code to pass `node_config` to prompt building methods if needed
- [x] Task 5: Add unit tests for skill_ref presence, absence, and None values

## Dev Notes
- The `IndependentAgent` class is located at `autoBMAD/docuswarm/agents/independent.py`
- The `NodeTaskConfig` dataclass (from `autoBMAD/nodes/loader.py`) now includes `skill_ref: str | None = None`
- The skill hint should be formatted as: `"Use the `{skill_ref}` skill to complete this task."`
- Consider adding the skill hint near the beginning of the system prompt for maximum visibility
- Ensure the hint is only added once per prompt construction
- The `node_config` object should already be available within `IndependentAgent` during execution
- Backward compatibility is critical - existing nodes without `skill_ref` must not break

### Implementation Summary
Story 32.7 implements automatic skill invocation hints in the system prompt when a node's task has a `skill_ref` configured.

**Key Changes:**
1. **Contract Builder (`contract_builder.py`):**
   - Added `skill_hint_section: str` field to `IndependentPromptContract` TypedDict
   - Added `_build_skill_hint_section(node_id: str) -> str` method that:
     - Loads node configuration via `NodeLoader.load(node_id)`
     - Extracts `skill_ref` from `node_config.task.skill_ref`
     - Returns formatted hint `"Use the `{skill_ref}` skill to complete this task."` if skill_ref is truthy
     - Returns empty string if skill_ref is None, empty, or if any exception occurs (graceful handling)
   - Updated `build_independent_contract()` to include `skill_hint_section` in the contract
   - Updated `render_independent_system_prompt()` to include skill hint between persona_section and instructions_section

2. **Node YAML Configurations:**
   - Added `skill_ref` field to all 5 node configurations in `autoBMAD/nodes/`
   - analyst: `bmad-product-brief`
   - pm: `bmad-create-prd`
   - ux: `bmad-create-ux-design`
   - architect: `bmad-create-architecture`
   - po: `bmad-create-epics-and-stories`

3. **Test Coverage:**

     - Skill hint presence when skill_ref is configured
     - No hint when skill_ref is None or missing
     - Correct hint format matching template
     - All 5 node types with their respective skill_refs
     - Backward compatibility with old configurations
     - Edge cases (special characters, whitespace, long names)
