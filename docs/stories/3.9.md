- Use timestamps for ordering runs (start_time descending for latest)
- StateManager must support `list_node_runs(node_id, context_hash, limit)` query
- Run tracking integrates with checkpoint system - each run gets unique thread_id
- Consider indexing node_id and context_hash columns for query performance
- Run history should be retained for at least 30 days or configurable retention period

## Implementation Details

### NodeRunTracker Class
```python
import uuid
from typing import List, Optional, Dict, Any

class NodeRunTracker:
    """Tracks node execution runs."""

    def __init__(self, state_manager: StateManager):
        self.state_manager = state_manager

    def generate_run_id(self) -> str:
        """Generate 8-character run ID."""
        return str(uuid.uuid4())[:8]

    async def list_runs(
        self,
        node_id: str,
        limit: int = 10
    ) -> List[Dict[str, Any]]:
        """List run history for a node."""
        return await self.state_manager.list_node_runs(
            node_id=node_id,
            limit=limit
        )

    async def get_latest_run(
        self,
        node_id: str,
        context_hash: str = None
    ) -> Optional[Dict[str, Any]]:
        """Get latest run for a node, optionally filtered by context_hash."""
        runs = await self.state_manager.list_node_runs(
            node_id=node_id,
            context_hash=context_hash,
            limit=1
        )
        return runs[0] if runs else None
```

### Database Schema Requirements

- Columns: run_id (PK), node_id, context_hash, start_time, end_time, status, deliverable_json, questions_json, evaluation_json
