## Dev Notes
- **Message 格式变化**: 从 `kimi_agent_sdk.Message` 对象转为标准 Python dict，格式为 `{"role": "user|assistant|system", "content": str | list}`
- **Content 类型处理**: Claude SDK 的 content 字段可能是字符串或列表（包含 text/image/tool_use blocks），需要兼容处理
- **向后兼容**: 无需保留 Kimi 格式兼容代码，完全迁移到 dict 格式
- **错误处理**: dict.get() 返回 None 时应有默认处理逻辑
- **参考实现**: 参照 Story 17.1 (IndependentAgent) 的实现模式

### 代码示例

```python
# BEFORE (移除前)

from kimi_agent_sdk import Message

async def _call_llm(...) -> list[Message]:
    sdk_response: list[Message] = await self.session_manager.single_prompt(...)
    return sdk_response

def _parse_response(self, response: list[Message]) -> dict[str, Any]:
    # 处理 Message 对象
    for msg in reversed(response):
        if msg.role == "assistant" and msg.content:
            content_raw = msg.content
            break
```

```python
# AFTER (新实现)

async def _call_llm(...) -> list[dict[str, Any]]:
    """调用 LLM 并返回 dict 格式消息列表"""
    result = await self.session_manager.single_prompt(...)
    return result

def _parse_response(self, response: list[dict[str, Any]]) -> dict[str, Any]:
    """使用 dict 格式解析响应"""
    for msg in reversed(response):
        if msg.get("role") == "assistant":
            content_raw = msg.get("content")
            # 处理 content 可能是 str 或 list
            break
```
