### 原验证逻辑摘要
**Independent Output Validation**:
- 验证输出包含 `file_path` 字段且不为空
- 验证 `content` 字段存在且非空
- 验证文件路径格式合法
- 可选：字数统计、必需章节检查

**Evaluator Output Validation**:
- 验证 `verdict` 字段为枚举值："APPROVED" | "REJECTED" | "NEEDS_REVISION"
- 验证 `feedback` 字段存在且非空
- 验证 `confidence` 字段为 0-1 之间的浮点数
- 验证 `suggestions` 字段（如 verdict 为 NEEDS_REVISION）

### ValidationRuleRegistry 集成
```python
# 示例：节点级规则获取
rules = self._rule_registry.get_rules(node_id)
min_word_count = rules.get("min_word_count", 100)  # 全局默认值
```

### 错误处理策略
- 策略类不直接抛出异常，返回 `ValidationResult` 包含所有问题
- 调用方（如 DualAgentRunner）根据 `ValidationResult.valid` 决定流程
- 严重错误（如缺失 `verdict`）标记为 `severity=ERROR`
- 建议性规则（如字数偏少）标记为 `severity=WARNING`

- 或迁移到 `tests/unit/context/test_validator.py`
