## Dev Notes
- **架构考量**: ToolRegistry 使用类变量 `_tools` 存储注册表，确保全局唯一实例
- **类型安全**: handler 字段使用 `Callable[[Any], Awaitable[ToolResult]]` 类型，接受任意参数
- **注册机制**: 支持重复注册，后注册的同名工具会覆盖之前的工具

- **命名规范**: 遵循项目命名规范，使用 snake_case 方法名
- **错误处理**: get() 方法在工具不存在时返回 None，不抛出异常
- **导入依赖**: 需要导入 ToolResult 从 docuswarm.models.tool 模块

### Technical Implementation Details

```python
# ToolDefinition dataclass
@dataclass
class ToolDefinition:
    """工具定义。

    描述一个工具的名称、描述、参数模型和处理函数。

    Attributes:
        name: 工具唯一标识符
        description: 工具功能描述，用于生成工具列表
        parameters: Pydantic 参数模型类
        handler: 异步处理函数
    """
    name: str
    description: str
    parameters: type[BaseModel]
    handler: Callable[[Any], Awaitable[ToolResult]]
```

```python
# ToolRegistry class
class ToolRegistry:
    """工具注册表 - 统一管理所有工具。

    提供工具的注册、查询、列举功能。
    所有工具通过显式注册而非 YAML 配置进行管理。
    """

    _tools: dict[str, ToolDefinition] = {}

    @classmethod
    def register(cls, tool: ToolDefinition) -> ToolDefinition:
        """注册工具到注册表。

        Args:
            tool: 工具定义对象

        Returns:
            已注册的 ToolDefinition 对象
        """
        cls._tools[tool.name] = tool
        return tool
```
