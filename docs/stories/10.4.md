## Dev Notes
- **httpx Assessment**: The KimiClient in `docuswarm/llm/client.py` used httpx for HTTP requests. Since KimiClient is being removed in Story 10.1, httpx should no longer be needed unless other modules import it directly.
- **langchain-openai Assessment**: This was likely added for ChatOpenAI compatibility. With the SDK migration to kimi-agent-sdk, verify if LangGraph still requires it for any adapter layers.
- **Version Pinning Strategy**: Use lower-bound pins (>=) rather than exact pins to allow security updates while maintaining compatibility. Review existing pins for consistency.
- **Dependency Conflicts**: After removing packages, verify no conflicts arise with transitive dependencies. Pay special attention to pydantic version compatibility with langgraph.
- **Migration Reference**: See Epic 10, Section 2.3 for the final dependencies list and Section 4.1 for removed module mappings.
