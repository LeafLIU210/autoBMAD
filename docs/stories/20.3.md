# Story 20.3: IndependentAgent Exception Migration

## Status

**Status**: Ready for Done

**Last Updated**: 2026-03-02 11:29:44

## Story
**As a** developer,
**I want to** update IndependentAgent to use DocuSwarm unified exceptions,
**So that** it no longer depends on Kimi SDK exceptions and follows the统一的异常处理架构.

## Acceptance Criteria
- [x] 移除 `kimi_agent_sdk` 相关异常导入 (MaxStepsReached, RunCancelled, etc.)
- [x] 更新异常捕获逻辑，使用统一异常 (StepLimitExceeded, SessionCancelled)
- [x] 更新异常抛出逻辑，使用统一异常 (LLMCallError, SessionError)
- [x] 保留原始异常链 (`from e` 语法)
- [x] 所有日志记录使用新的异常属性 (e.g., `max_steps` from StepLimitExceeded)
- [x] 类型提示从 `list[Message]` 更新为 `list[dict[str, Any]]`

## Dev Notes
- **异常映射关系**:
  - `MaxStepsReached` → `StepLimitExceeded`
  - `RunCancelled` → `SessionCancelled`
- **异常链保留**: 所有 `raise ... from e` 模式必须保留，确保原始错误信息不丢失
- **日志字段变更**:
  - 旧: `error=str(e)`
  - 新: `max_steps=e.max_steps` (从异常对象直接获取)
- **返回值变更**:
  - 旧: `list[Message]` (Kimi SDK Message 对象)
  - 新: `list[dict[str, Any]]` (字典格式消息)
- **SessionManager 调用**: 改用 `await self._session_manager.execute(prompt=full_prompt)` 替代直接 `session.prompt()`
