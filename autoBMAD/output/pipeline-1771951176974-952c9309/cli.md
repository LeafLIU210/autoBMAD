## 3. 错误处理交互

### 3.1 输入验证错误
```bash
$ bubble-sort sort a b c

❌ 输入错误
──────────────────────────────────
无效的输入: 'a' 不是有效数字

💡 使用示例:
  bubble-sort sort 5 3 8 1 9
  bubble-sort sort 10,5,3,8

查看帮助: bubble-sort sort --help
```

### 3.2 参数范围错误
```bash
$ bubble-sort generate --size 200

⚠️  警告
──────────────────────────────────
数组大小 200 超过推荐值(100)
可视化模式可能显示异常

是否继续? [y/N]: 
```

### 3.3 终端不支持颜色
```bash
$ bubble-sort sort 5 3 8 --visualize

⚠️  终端兼容性警告
──────────────────────────────────
当前终端不支持彩色输出
已自动切换到纯文本模式

💡 如需强制启用颜色,使用 --force-color
```

## 4. 帮助信息设计

### 4.1 主帮助
```bash
$ bubble-sort --help

🫧 冒泡排序CLI工具 v1.0.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一个交互式的冒泡排序演示和性能测试工具

用法: bubble-sort [选项] <命令> [参数]

命令:
  sort       执行冒泡排序
  generate   生成测试数据
  benchmark  性能基准测试

选项:
  --version   显示版本信息
  --help      显示帮助信息

示例:
  bubble-sort sort 5 3 8 1 9
  bubble-sort sort 5 3 8 --visualize
  bubble-sort generate --size 20
  bubble-sort benchmark --size 100

更多信息: https://github.com/example/bubble-sort-cli
```

### 4.2 子命令帮助
```bash
$ bubble-sort sort --help

🔄 sort - 执行冒泡排序
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

用法: bubble-sort sort [选项] NUMBERS...

参数:
  NUMBERS...  要排序的数字序列

选项:
  --asc, --ascending    升序排序(默认)
  --desc, --descending  降序排序
  -v, --visualize       启用可视化演示
  --delay FLOAT         可视化延迟(秒,默认0.3)
  -s, --stats           显示详细统计信息
  --no-color            禁用彩色输出

示例:
  bubble-sort sort 5 3 8 1 9
  bubble-sort sort 10 5 3 --desc
  bubble-sort sort 5 3 8 --visualize --delay 0.5
```

## 5. 配置文件支持

### 5.1 配置文件位置
```
~/.config/bubble-sort/config.toml
```

### 5.2 配置示例
```toml
[display]
color = true
animation_delay = 0.3
show_stats = true

[limits]
max_array_size = 100
max_value = 10000
min_value = -10000

[benchmark]
default_iterations = 10
warmup_iterations = 3
```

### 6.2 颜色语义
| 颜色 | 含义 | 使用场景 |
|------|------|----------|
| 🟢 绿色 | 成功/完成 | 排序完成、成功消息 |
| 🔵 蓝色 | 信息/提示 | 帮助信息、提示 |
